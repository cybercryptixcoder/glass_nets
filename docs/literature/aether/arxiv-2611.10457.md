# Represented but Not Used: Value–Policy Dissociation in LLM Agents

- **Key:** arxiv-2611.10457
- **Authors / organisation:** Yuzhang Luo, Mohamed Aghzal, Liangming Pan, Ziyu Yao; Peking University / George Mason University
- **Date:** 2026-11-07
- **Link:** https://arxiv.org/abs/2611.10457
- **Kind:** paper
- **Read from:** full text (arXiv HTML v1, ~85.8k clean chars: abstract, §1–§7, limitations, references, Appendices A–F; figures NOT inspected, so every number below is a Table cell or an explicit sentence)
- **Relevance to us:** 3 (central)

## What they wanted, and why
A failing agent trajectory does not say *which* step failed. The model may never have worked out what an action would cost it, or it may have worked that out and then chosen against it. Earlier mechanistic work on agents stopped at the world state — board positions, spatial layout, a cognitive map of the environment — and the authors note that their own looping agents encoded the partial map precisely while still repeating an inferior move, so state representation is not where the failure lives. They therefore lift the object of study from *what the model knows about the world* to *how it scores its own candidate actions*, using the reinforcement-learning notion of action value, and ask two questions: when the agent picks a worse action, is the value of the better one absent, or present and unused? If present, can it be turned into better behaviour? The larger goal is a diagnosis of agent failure that is not available from behaviour alone.

## What they studied
Three instruction-tuned models — Qwen2.5-7B-Instruct, Qwen2.5-32B-Instruct and GPT-OSS-20B (run with its native reasoning effort set to low) — in two partially observed sequential environments. **Grid**: 1,400 maps of 5×5, four movement actions, local 4-cell feedback folded into a cumulative memory that is rendered into the prompt, success within 24 steps, split 1,200/100/100. **WebShop**: 1,502 tasks, search-and-click with a 15-step cap and a terminal reward in [0,1]. The unit of analysis is a **direction in the residual stream** — a linear value readout at one layer, and a linear map from value changes to hidden-state changes at each layer — evaluated at decision states rather than at final outputs. All activations are taken from the *input decision prompt* (final prompt token in Grid, the candidate's identifier span in WebShop), before any reasoning or action token is generated.

## How they did it
1. **Behaviour first.** Zero-shot success / reward plus a *loop rate*: the fraction of trajectories containing at least one A→B→A→B action cycle.
2. **A separate state check.** A 25-cell F/O/U readout of the observed map, so that a failure to reach the goal could not be blamed on a failure to encode the environment.
3. **Value targets, chosen per environment.** Grid: V(s,a) = minus the shortest-path distance from the successor cell to the goal *on the agent's current partial map*, unrevealed cells treated as passable — an optimistic, task-derived, policy-free value. WebShop: the policy-conditioned continuation value, estimated by averaging the terminal reward over **40 sampled continuations** per candidate click, with candidates drawn from 48 samples at temperature 0.7 / top-p 0.9 under validity constraints.
4. **Linear readouts.** Grid trains one probe at the final prompt token that jointly predicts the four action values and scores it by whether the gold best action ranks first; WebShop trains a pairwise logistic classifier on candidate-span activation *differences* and scores pairwise ranking accuracy. Both are compared against task-informed heuristics — Manhattan distance in Grid, TF-IDF lexical match in WebShop — and both are reported layer by layer with cluster-bootstrap intervals on a held-out split.
5. **A cross-classification instead of a correlation.** At each decision state they read out whether the policy's greedy action is correct and whether the probe's top-ranked action is correct, giving four cells. This is the paper's central instrument: it turns "the probe is accurate" and "the policy is accurate" into a joint table.
6. **Intervention, three ways.** Edit the hidden state by α·d at layer ℓ and fit the *steering slope* κ — the OLS slope of the change in the log-probability margin between the readout-preferred and readout-disfavoured action over α ∈ {0,1,2,4,8,16}. The three constructions are: **Probe (calibrated)**, the minimum-norm least-squares edit that produces a desired change in the probe's own output (pseudoinverse in Grid, projection onto the unit probe direction in WebShop); **NVT** (Natural Value Transport), a ridge regression B_ℓ fitted from (Δ value, Δ hidden state) pairs to predict how the representation moves when value moves, applied as d = B_ℓ δv; and three controls matched in norm — **Probe (same-norm)**, **Shuffled NVT** (the value↔activation pairing is broken, by permuting pair indices before fitting in Grid or by permuting the fitted transport's coordinates in WebShop) and **Random** (an isotropic Gaussian direction). Grid's NVT training pairs are counterfactual prompt pairs where one cell is marked obstacle versus free, positions and goal held fixed.
7. **Closed loop.** A sensor/actuator controller — the value readout picks the preferred action, an NVT edit at (often a different) layer pushes toward it — rolled out over 100 held-out Grid maps and 454–671 WebShop episodes in five task-disjoint folds, with steering strength tuned per model.

## What counts as an explanation here
A probe plus a steering vector, and explicitly a *partial* one. The paper's claim is a dissociation, not a mechanism: it shows that a linearly decodable quantity exists, that the policy does not follow it, and that a different linear map — one fitted to how the representation actually moves with value — is the thing that can be pushed. Nothing here explains where the value computation happens or which components produce it; the readout is a coordinate, not a circuit. The interesting formal move is that the authors deliberately refuse to name a construct: they score only the *contrast* between actions, on the argument that the model's internal value scale need not be theirs.

## How they judged success
Grid: held-out top-1 ranking accuracy of the four-way readout against the shortest-path target, with Manhattan distance as the baseline and detour states (where obstacles make shortest-path differ from Manhattan) called out separately; plus a 25-cell map-accuracy and exact-map check with a positional-majority baseline, and a 25-cell *global distance-field* regression. WebShop: held-out pairwise ranking accuracy against sampled continuation value, with TF-IDF as the baseline. Dissociation: the 2×2 joint-correctness table, with the asymmetry between its off-diagonal cells as the statistic. Intervention: per-layer steering slope with three norm-matched controls, and — for behaviour — paired baseline→steered success/reward, loop rate, and *flip rate* (share of decisions whose action changed). Robustness: invalid-action rate under steering, a matching 30-step interaction-budget arm, and five task-disjoint WebShop folds so that the readout and the transport are fitted on data that excludes the evaluation tasks.

## What they found
- **The agents are weak and they loop.** Grid success 12.64% (Qwen-7B) / 54.57% (GPT-OSS-20B) / 58.14% (Qwen-32B), with loop rates 81.2% / 32.5% / 41.6%. WebShop reward 0.509 / 0.250 / 0.293 with loop rates 8.9% / 36.3% / 29.4% — the 7B model beating both larger ones. A 30-step budget does not fix the ordering (GPT-OSS-20B 0.250 → 0.284, Qwen-32B 0.293 → 0.297, Qwen-7B 0.509 → 0.517) and *raises* loop rate for GPT-OSS-20B (36.3% → 53.3%), so the deficit is not a horizon artefact.
- **The state is not the problem.** The 25-cell F/O/U map decodes at 96.28–98.20% cell accuracy and 72.18–79.73% *exact-map* accuracy, where the positional-majority baseline gets 60.7–61.5% per cell and **0.00%** exact. A single prompt-last hidden state also yields a whole 25-cell distance-to-goal field that beats Manhattan specifically on detour cells.
- **Value is linearly readable where the policy fails.** Value readout accuracy in Grid is above the Manhattan baseline by mid-to-late layers and, crucially, holds on detour states where Manhattan misorders the actions — evidence the model is not simply running a geometric shortcut. WebShop pairwise ranking sits near 80%.
- **The dissociation is strongly asymmetric.** Grid, policy-wrong-but-probe-right: 58.3% (Qwen-7B), 37.5% (GPT-OSS-20B), 34.2% (Qwen-32B); probe-wrong-but-policy-right: 1.8%, 0.1%, 0.2%. WebShop: 43.9% / 39.8% / 39.8% against 8.3% / 12.7% / 10.3%. On the 7B Grid model, the state in which the policy is right *and* the probe is wrong is 0.3% of decisions — the readout is almost never the thing missing.
- **Probe-direction steering mostly does not work; a learned transport does.** Probe (calibrated) produces little policy response at any layer; Probe (same-norm) produces positive slopes in places, suggesting overlap with policy-sensitive subspaces, but not a coherent layer pattern. NVT shows a coherent late-layer policy-responsive region in all three models and both tasks, and neither Shuffled NVT nor Random reproduces it — so the effect is carried by *which* direction, not by magnitude.
- **Closed-loop steering improves behaviour, unevenly.** Grid success 0.140 → 0.300 (Qwen-7B, loops 85.0% → 64.0%), 0.580 → 0.640 (GPT-OSS-20B), 0.590 → 0.680 (Qwen-32B, loops 41.0% → 32.0%). WebShop reward 0.473 → 0.501 (Qwen-7B), 0.417 → 0.458 (GPT-OSS-20B), **0.358 → 0.452** (Qwen-32B) with loop rate barely moving (2.0% → 1.8%). Flip rates 16.5–55.1%, i.e. the controller really changes actions during interaction rather than only widening a log-margin. Invalid actions are not consistently reduced (Qwen-32B WebShop 9.7% → 6.2%; Qwen-7B Grid 0.0% → 0.17%).

## Limits and open problems they name
Three models, two families, two environments — generality across agent architectures and decision domains is untested. "Prospective value" is task-dependent by construction: an exact shortest-path target in Grid and a sampling-dependent, policy-dependent estimate in WebShop, and the two are not the same construct (Appendix A.3 argues they serve the same purpose, which is an argument rather than a measurement). Only click actions in WebShop, not search. Linear readouts and a linear transport only, which support the separation but do not account for how value is computed or propagated. And the whole apparatus needs white-box access plus task-specific supervision — a readout and a transport must be fitted per environment — so it does not transfer to closed models or to settings without such labels.

**Limits I would add, marked as mine:** the value target in Grid is computed from the *same partial map* the state probe decodes, so "the probe knows the value" and "the probe contains the map" are not independent facts; the detour-state analysis narrows this but does not eliminate it. The steering-slope statistic is a linear fit over an α grid that includes α = 16, so a saturating nonlinearity can still read as a slope; the controls are norm-matched, which rules out magnitude but not, e.g., a shared "large edit in any late-layer direction that correlates with the probe" effect — Random is the only arm testing that, and it is a single draw per instance and layer. The closed-loop arm tunes α and both layers per model on held-out instances (Table 7), so the reported gains include a configuration search of non-trivial size, and the Grid n is 100 maps. And the flip rate of 55.1% with a WebShop reward gain of 0.09 says many flips are not improvements — the controller is being scored at the episode level while acting at the decision level.

## What we take from it
- **Method — the joint-correctness table.** Cross-classify *the probe's verdict* and *the policy's verdict* at the same states instead of reporting two accuracies. It is one extra column on any probe battery we already run and it converts "our probe is 80% accurate" into a statement about whether the readout is the bottleneck. The sign of the asymmetry is the finding.
- **Measure — the steering slope as a layer-wise curve, not a single peak.** Fit the change in the decision margin against intervention strength with an intercept, report the slope per layer, and require the curve's *shape* (a coherent band) rather than one significant layer; this is the cheapest way to distinguish "this direction is causally wired to the policy" from a lucky layer.
- **Method — fit the transport, do not invert the probe.** Their cleanest negative result is that steering along the probe's own decoded coordinates barely moves the policy, while a ridge map learned from (Δ value, Δ representation) pairs does — even though NVT is *fitted to the probe's outputs* in Grid, i.e. two maps with the same input produce very different causal reach. For a predictive model this is the difference between "we can read X off the state" and "we can push the state along X", and it argues that any steering we ship carries a transport fitted on matched counterfactual pairs (here: one cell toggled obstacle↔free, everything else fixed).
- **Warning — an accurate readout is not a used one, and behaviour cannot tell you which you have.** For a model that predicts a network's action from its state, the empirically decodable value is an *upper* bound on what the policy will do; the dissociation quantifies the gap. Any claim of the form "the model represents the goal" should be accompanied by the joint table, because representational success and behavioural success are separate booleans — the same defect this folder found in cross-model similarity matches and in psychometric profiles, arriving on the action side.
- **Warning — a competence floor makes the mechanism claim testable.** The 7B Grid agent succeeds 12.64% of the time, and its probe is still 58.3%-of-states right where the policy is wrong; the paper can make the dissociation claim precisely because it measured both. Applying the same discipline: state the policy's chance level and the probe's accuracy together, since a "dissociation" measured on a model that cannot do the task at all is a different object.

# Programmable Semantic Interventions: Learning Causal Carriers from Behavioral Programs

- **Key:** arxiv-2611.21307
- **Authors / organisation:** Paolo Muratore, Mackenzie Weygandt Mathis — EPFL
- **Date:** 2026-11-16
- **Link:** https://arxiv.org/abs/2611.21307
- **Kind:** paper
- **Read from:** full text (HTML, §§1–4 + Appendices A.2, A.3, A.4, A.12)
- **Relevance to us:** 3 (central)

## What they wanted, and why
Causal abstraction is the part of interpretability that asks whether a network *uses* a high-level variable, not merely whether the variable can be read off an activation: pick a low-rank subspace, swap it between two prompts, and check that the network's intervened output agrees with what a simple high-level model says should happen. The trouble, as they describe it, is the price of admission. To know what "should happen" for each prompt pair, current methods require a counterfactual dataset whose answers are produced by running an executable algorithm the investigator must write *before* studying the model — which forces an algorithmic commitment for every behaviour studied and excludes behaviours nobody can write down. Their motivating observation is that the usual scoring criterion never inspects the algorithm at all: it only uses the answer the algorithm emits under the intervention. So they ask whether the investigator can supply just that answer-level relation and nothing else — a two-line declaration instead of a program — and recover the same causal subspace. If it works, the causal-abstraction test becomes available for tasks where the "true" computation is unknown, which is the regime our own work lives in.

## What they studied
Frozen instruction-tuned and small language models — gemma-2_2b, llama-3.1_8b, qwen-2.5_0.5b on the MIB causal-variable benchmark, plus gpt2-small for indirect-object identification — with the unit of analysis a **learned rank-r linear subspace of the residual stream at one layer and one token position** (rank set per task/site to whatever the official DAS baseline used, so the comparison is at equal capacity). The variables are benchmark variables with small answer sets: the *position* of the correct multiple-choice option, the *answer symbol* (letter), the *carry* out of the units digit in two-digit addition, the *continent/country/language* of a city in RAVEL, and the indirect-object variable in IOI. Natural ARC-Easy science questions are used as the case where no short algorithm exists.

## How they did it
1. **Declare a semantic program**, two objects fixed before training: an *outcome library* — the answers the variable can take, in the model's own vocabulary (the prompt's four option labels in listed order; the 26 leading-space letters; the two sums with and without the carry; one deduplicated first-token library of city attributes for RAVEL) — and a *transport rule* saying how the library reading should change under an intervention (full swap in most tasks; a gated swap for RAVEL that is a no-op when the base prompt is not asking about the intervened attribute; a table for IOI, built from the benchmark's own linear model and therefore explicitly **not** measured from the subject).
2. **Read the model inside that frame.** For a prompt, take the log-probability the frozen model assigns to each library entry and normalize over the library: the normalizer's mass Z is how much of the model's probability the frame captures at all, and the normalized vector q is "the model's reading" of the variable. Both are measurements, not labels.
3. **Build targets without ground truth.** Pair base and source prompts by a random derangement inside a group the program declares comparable; the target reading for the base is the transport of the source's *own measured* reading. Training minimizes the divergence (cross-entropy on log-probabilities) between the intervened model's library reading and that target, over pairs, by gradient descent on the orthonormal subspace. Because the target is measured, it is defined even on prompts the model answers wrongly, and no curated pair list is needed.
4. **Intervene as a projection:** replace the base's projection onto the subspace with the source's and keep the base's complement untouched, then continue the forward pass from the edited activation and re-read the library.
5. **Ablate what a counterfactual dataset buys**, one site, fixed rank/optimizer/budget: keep the pair list but permute which source goes with which base; swap the target between the model's reading and the oracle answer; change only the donor pool size; and remove the gold-label correctness filter entirely.
6. **Control with the same interface.** Since the library fixes a coordinate system with known semantics, a *requested* reading (any point of the probability simplex over the library) can be named directly and realized by a learned linear edit inside the same subspace, with a magnitude clip set at a high quantile of real interchange displacements. The subspace and a small gain controller are trained jointly (donor term + control term), with half the requested readings drawn uniformly from the simplex so no prompt needs to exhibit them — donor-free steering.
7. **Sweep every layer × the benchmark's token positions** (52–96 runs per table cell, 1,188 in total), take the best fixed position per layer, and report the depth-mean with the best layer in parentheses; a random same-rank subspace at the same sites is the floor.

## What counts as an explanation here
A **low-rank causal carrier**: a linear subspace whose interchange reproduces the variable, plus a coordinate frame with declared semantics in which arbitrary readings can be requested. It is partial by design — one variable, one site, one rank — and it is explicitly *causal* in the interchange sense rather than descriptive. Its predictive content is a counterfactual one: what the model will answer when the variable's value is swapped, and (for the controlled variant) what it will answer when a reading nobody's prompt exhibits is requested.

## How they judged success
Primary metric is **interchange intervention accuracy (IIA)** — the fraction of interventions where the intervened model's output matches the high-level model's — against the benchmark's published baselines (DAS, DBM, DBM+PCA, DBM+SAE, Full Vector interchange) and a **random same-rank subspace** null, at matched rank; training loss is a differentiable relaxation of it. Secondary: KL from the donor's reading to the edited recipient's (on held-out pairs), greedy agreement with the donor's own answer (split out separately on pairs whose donor the model answers wrongly), and for control, the fraction of held-out *corner* requests realized plus **total variation from the requested reading on interior requests** no prompt exhibits. Two decision rules are audited side by side (benchmark rule = decode over the whole vocabulary and check the expected answer appears; declared-library rule = does the intervened model prefer the requested entry), because they come apart when answers span several tokens.

## What they found
- **Localization without counterfactual labels matches or beats the supervised baseline.** MCQA: Ψ reaches 94 / 98 / 92 (O_Answer) and 76 / 80 / 75 (X_Order) at its best layer on the three models, against DAS at 95 / 94 / 86 and 77 / 77 / 78, and well above the 7–19 / 16–33 random floor and the Full-Vector interchange. ARC-Easy and arithmetic are mixed but competitive: ARC (Easy) O_Answer 95 and 97 (gemma-2_2b, llama-3.1_8b) against DAS 88 and 88; arithmetic carry 38 versus 31 on gemma-2_2b and 52 versus 54 on llama-3.1_8b. RAVEL is the loss: Ψ trails DAS in all six cells (e.g. continent 68 versus 75 on gemma-2_2b) while leading the other published methods in all but one.
- **The ablation says the counterfactual *pairing* is nearly worthless and the extra donors do the work.** Holding the pair list, its base multiplicities and the 544 optimizer updates and permuting only which source accompanies which base costs 0.07 points against a model-reading target (89.94 vs 89.87) and 1.34 against the oracle answer. Shrinking the donor pool to the pair list's distinct sources costs 5.63 points (84.24). Letting the derangement draw on all 383 eligible observations, rather than the 108 the pair list uses as bases, reaches 90.84 ± 0.9 against 91.40 ± 0.5 for the fully supervised cell. Removing the correctness filter costs 0.9 points.
- **Reading the model beats reading the gold answer, precisely where the model is wrong.** On ARC with 2,241 training questions (79.7% answered correctly) and 589 held-out pairs: swapping the carrier reproduces the donor's answer on 94.8% of pairs with a model-distribution target, at KL 0.020, against 0.117 (one-hot model labels) and 0.090 (gold labels); on the 111 pairs whose donor the model answers wrongly it is 85.9% against 79.3% and 72.1%; yet on the benchmark's own correctness-filtered score the gold-trained subspace is ahead, 71.45 against 70.03.
- **A declared frame can be steered to readings no prompt exhibits.** Jointly trained, corner requests are realized 94.8% of the time at the MCQA site and 63.7 ± 2.6% at the arithmetic site, against a donor interchange's 50.8% (chance) on arithmetic; the same controller inside a rank-matched DAS, PCA or random carrier reaches 81.7%, 83.9% and 34.2%. On interior requests the total variation to the request is 0.10 against 0.18 for an interchange and 0.44 for no edit.
- Encoding invariance and a caveat: a carrier trained on one option labelling transfers to lowercase labels at 100%, and to digit labels asymmetrically — a digit donor moves an original-label recipient 92.4–95.8% of the time, while a digit recipient follows the donor only 45.3–49.3%, though the model answers digit-labelled questions correctly 95.0% of the time. Arithmetic shows the two decision rules diverging hard at layer 19: 46.3 under the benchmark's whole-vocabulary rule against 71.3 under the declared-library rule.

## Limits and open problems they name
The programs here were easy to write; naming a library that is semantically clean *and* holds much of the model's probability may be hard for abstract variables, and for the carry the library itself demands solving the task. Model-read targets are only as good as the model's distribution over the library — on RAVEL the reading is often diffuse (the gold continent is the top entry on only 43.8% of prompts) and Ψ loses to DAS in every cell. Matching the declared transport does not guarantee identification: the supporting subspace need not be unique, and a subspace can move the output along a pathway unrelated to the variable it is named after. Gold answers still enter as the correctness filter and via the benchmark's cut position (though removing the filter costs under a point and §3.2 uses neither). The IOI task is not an instance of the interface at all — its target is computed from the benchmark's own linear model — so every "measured from the subject" claim covers MCQA, ARC, arithmetic and RAVEL only. Reported localization numbers are single-seed (one repeated site gave ±0.9 points).

## What we take from it
A **method and a reporting convention**, both directly usable for a predictive white-box model:
- **Declare the answer space, measure the reading.** The cheapest causal claim we can make about a variable is not "this direction decodes it" but "interchanging this subspace moves the model's probability *within a declared set of answers* as the answer-level rule says". Writing the library costs a line; it turns the intervention test into something checkable on unlabelled data and on prompts the model gets wrong — and the wrong-answer stratum is where the model-derived target beat the gold-label target by 13.8 points (85.9 vs 72.1). If our predictive model is trained to match human labels rather than the network's own distribution, this is a direct warning about where it will be least faithful.
- **Report the frame's coverage (Z) beside the accuracy.** A target the library captures only part of makes every downstream number a number about that part; RAVEL's diffuse reading is the same paper's own failure, and it shows up as a coverage/entropy fact *before* any training.
- **Price the supervision, don't assume it.** The permutation/shrink/drop arms are a template we should copy verbatim for any paired-data claim we make: swap the pairing, shrink the pool, drop the labels, then say which ingredient the result depended on. Here the "counterfactual dataset" everyone builds turned out to be worth 0.07 points and its donor *pool* worth 5.63.
- **Localize and write through one object.** Training the subspace under both the donor and the control objective beat bolting a controller onto a frozen localization carrier (94.8 against 81.7 for the same controller in a DAS carrier), and it buys requests no prompt exhibits — the operationally useful form of "predict under intervention".
- A warning to carry: the two decision rules disagree by 25 points at one site because the answer spans three tokens. Our own evaluations decode over the vocabulary; where the declared unit is multi-token, that choice is a free parameter and must be stated.

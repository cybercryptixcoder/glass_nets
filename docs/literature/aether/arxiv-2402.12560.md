# CausalGym: Benchmarking causal interpretability methods on linguistic tasks

- **Key:** arxiv-2402.12560
- **Authors / organisation:** Aryaman Arora, Dan Jurafsky, Christopher Potts; Stanford University (all three at stanford.edu addresses)
- **Date:** 2024-02 (v1 2024-02-19)
- **Link:** https://arxiv.org/abs/2402.12560
- **Kind:** benchmark
- **Read from:** full text
- **Relevance to us:** 3 (central)

## What they wanted, and why

Two literatures need each other and have not met. Computational psycholinguists use language models as subjects — comparing surprisal, testing grammaticality — but study only input and output behaviour, never the mechanism that produces it. Interpretability researchers propose methods for finding the internal feature behind a behaviour, but evaluate each one on a bespoke dataset, so the field has no shared task on which a probe, a difference-in-means direction, a PCA direction and a learned intervention direction can be compared on the same ground. The authors build that shared ground out of an existing syntactic benchmark, extend it with a control-task correction borrowed from the probing literature, and then use it to ask how a mechanism for a syntactic rule develops across a training run. The larger goal is to make causal evaluation of interpretability methods a routine, standardised step rather than a case-by-case demonstration.

## What they studied

The unit of analysis is a **one-dimensional direction in the residual stream at one layer and one token region** — the object every method under test returns, and the quantity the intervention acts on. Models: the Pythia family at nine sizes from 14M to 6.9B (with 12B named as part of the series), all trained on the same data in the same order with released checkpoints, which is what makes the training-dynamics study possible. Tasks: 29 English templated minimal-pair tasks, 28 converted from SyntaxGym suites plus one new gender-agreement task, grouped into agreement, licensing, garden-path, gross syntactic state and long-distance dependency families. Methods compared: seven — DAS, linear probing, difference-in-means and LDA (supervised, in the loose sense that they see labels), and PCA, k-means and a random vector (unsupervised).

## How they did it

Each SyntaxGym suite supplies item templates with named regions and a feature that alternates across conditions. They keep only the two grammatical conditions, so each item becomes a counterfactual pair: a base sentence and a source sentence that differ only in the alternating feature and in the next token they predict. Regions become slots, and slots are recombined across items under a type scheme so that large numbers of fresh, span-aligned pairs can be generated with the label-bearing slots varied and everything else held constant; hand-checking removed combinations that read as ungrammatical. For a given layer and token region, the intervention replaces the base residual state with one interpolated along a supplied unit direction so that the base activation's projection is swapped for the source's, leaving the orthogonal complement untouched — the one-dimensional distributed interchange intervention. Every method's job is to produce that direction: DAS learns it by gradient descent through the frozen model on the counterfactual target token; probing, LDA, difference-in-means and k-means read it off from labelled activations; PCA takes the first principal component; the random arm samples a vector. Training sets are 400 pairs, evaluation 100, disjoint by construction, with both directions of each pair included so the label balance is exact and the supervised and unsupervised methods face the same comparison. Effect is measured as a per-item log odds ratio that rises both when the intervention makes the source label more likely and when the base label was preferred originally, averaged over items, maximised over regions within a layer, then averaged over layers. To separate a method's expressivity from its finding, they add a control task in which the same inputs are mapped to two arbitrary unrelated tokens instead of the real label words, preserving the class partition, and report selectivity as the original-task effect minus the control-task effect. Finally, the same pipeline is re-run on earlier Pythia-1B checkpoints to see when the mechanism appears.

## What counts as an explanation here

A **direction plus an effect**: a unit vector whose substitution behaviourally flips the model's next-token prediction in a controlled counterfactual. It is a localisation claim, not a description — nothing in the benchmark says what the direction means, only that intervening on it moves the output the way the high-level linguistic variable would. It is explicitly partial and site-indexed (layer, region), and the paper is careful that a direction with causal effect need not be the only such direction or a complete account of the behaviour. The strongest claim the paradigm supports is causal alignment of a representation with a high-level variable, in the causal-abstraction sense: the intervened model behaves as if its input had been the source.

## How they judged success

Primary metric: **overall odds ratio**, defined so that zero means no causal effect and larger means a bigger flip of the prediction, averaged over 100 held-out pairs, max over regions within a layer, mean over layers. Second metric: **selectivity**, the same quantity recomputed after the arbitrary-label control task and subtracted, so a method that works equally well on nonsense mappings is discounted. Both are reported averaged over all 29 tasks per model in the main table, with full per-task tables in the appendix annotated by task accuracy. Supporting measures: task accuracy of the base model per task (used as a filter — tasks the model barely solves are flagged), hyperparameter sweeps on a dev set for DAS learning rate, probe regulariser and bias term, and PCA component count, and a dev-set justification for the learning rate. Baselines are the other six methods; the appendix adds a vanilla full-vector interchange as an upper bound on expressivity. The random direction is printed in every table, and is the arm the whole paper is implicitly calibrated against.

## What they found

DAS finds the most causally efficacious features at every model size, and probing is consistently second, with difference-in-means third; the unsupervised methods trail badly, and LDA — despite seeing labels — sits barely above a random direction across the sweep. The margins are large: on Pythia-14M the average overall odds ratio is about 3.94 for DAS against 1.16 for probing, 1.04 for difference-in-means, 0.50 for k-means, 0.48 for PCA, 0.11 for LDA and 0.03 for random. But the selective picture complicates the ranking: DAS is not appreciably more selective than probing at small scales and at larger scales is less selective than probing or difference-in-means, so on the control-adjusted measure the gap between DAS and probing narrows — the authors read this as DAS's access to model outputs during training explaining a good part of its advantage rather than its direction-fitting being intrinsically better. The most striking single fact is that DAS finds appreciable causal effect on the model at initialisation, before any task mechanism can exist — the same result the Alpaca-scale interpretability work reported, and the reason the control task is needed at all. Task accuracy rises cleanly with scale (about 0.62 at 14M to 0.89 at 6.9B, averaged over all 29 tasks), so the benchmark does track competence. In the training-dynamics study, both case-study mechanisms appear in discrete stages rather than gradually: the NPI mechanism first lives at the NPI position and the main verb, then the auxiliary becomes important in middle layers while the NPI effect is pushed down to early layers, then an additional intermediate site is added — each stage arriving abruptly at a checkpoint boundary. The filler-gap mechanism takes longer and arrives in two stages, with the main verb joining the mechanism only after the 10K-step mark, and its final form moves the filler feature across several intermediate positions before the output. DAS and probing largely agree on which regions are most efficacious at each layer, which is what makes the region-level trajectory interpretable at all.

## Limits and open problems they name

The benchmark is English only and linguistic only; other languages and non-linguistic behaviours are untested and the authors expect results to differ. All models come from one family trained on one dataset in one fixed order, so the training trajectories are one model's learning path and not a general law of acquisition. Only one-dimensional linear interventions are benchmarked: multi-dimensional and non-linear methods are left to future work, and the paper acknowledges this is a restriction its linear-representation premise forced, not a considered verdict. The control task is the Alpaca-paper formulation rather than Hewitt and Liang's exact construction, because the input-to-label mapping here depends on token types and cannot be reproduced verbatim. The interventions act on a single region at one layer, so any mechanism that requires simultaneous intervention at several sites is outside the frame.

## What we take from it

Four things, three of them directly reusable in our own tables.

1. **A benchmark we can adopt rather than invent.** Templated minimal pairs with named regions, a 400/100 disjoint split, both pair directions included for label balance, and an effect scale calibrated by a random direction and a vanilla full-vector upper bound — this is the cheapest complete template in the folder for evaluating a direction claim. Our own prediction-under-intervention claims should be scored on held-out pairs that never entered the direction's fitting, and the base model's own accuracy on each task should be printed next to the effect, since a large effect on a task the model cannot do is not a demonstration of anything.
2. **The control task adapted to a causal setting, with an honest report of it.** Mapping the labels to arbitrary tokens and reporting the difference is the causal analogue of a probe's control task, and the crucial reporting choice is that the authors print the selectivity number beside the raw effect for every method rather than substituting it — because the pair is the finding: DAS wins on effect and mostly loses its advantage on selectivity. Any steering or patching score we report should carry the same twin, run with the same direction on shuffled labels.
3. **A warning about the initialisation arm.** A method with output access can produce a large "causal effect" before the model has any mechanism, so a single effect number with no control cannot distinguish explanation from expressivity. This is the third arrival in the folder at the same control (see the random-direction arm in the dictionary line and the amnesic random-erasure control), and it is the one we are most exposed to, since our read-outs are fitted against outputs by construction.
4. **A framing for trajectories.** Because Pythia's checkpoints share data order, the discrete-stage result is a legitimate claim about one model's development, and the instrument that makes it legible — the layer-by-region heat map at each checkpoint — is a cheap way to show a mechanism forming. We have no comparable longitudinal account, and this is the template for one: same task, same directions, checkpoint sweep, effect plotted by site.

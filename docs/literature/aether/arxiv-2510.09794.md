# Causality ≠ Decodability, and Vice Versa: Lessons from Interpreting Counting ViTs

- **Key:** arxiv-2510.09794
- **Authors / organisation:** Lianghuan Huang (University of Pennsylvania); Yingshan Chang (Carnegie Mellon University)
- **Date:** 2025-10-10 (v1; v2 and v3 do not exist)
- **Link:** https://arxiv.org/abs/2510.09794
- **Kind:** paper
- **Read from:** full text (v1 HTML: 66,847 raw bytes, 21 `math` == 21 `alttext` on the raw file, 22,662 chars / 391 lines after strip). Figures 2-5 were read from the prose that describes them, not inspected as images; the probe-accuracy plots are described only qualitatively, so no probe accuracy value in this entry is invented.
- **Relevance to us:** 2 (useful) - a short, deliberately small study of the exact question our white-box model has to answer per unit: does a representation's *readability* order the same units as its *use*, and where does the order invert? It is the folder's first entry in which the two arms are measured at every layer and every token type on the same model, so the mismatch is mapped rather than observed once.

## What they wanted, and why
Most interpretability work picks one of two instruments and reports what it finds: probing, which asks whether a variable can be recovered from a hidden state, or activation patching, which asks whether replacing that state changes the output. The authors say these have been treated as interchangeable lenses and that the field has no systematic account of when they agree. They choose a task where the answer variable is unambiguous (the number of objects in an image), fine-tune a small vision transformer on it, and then read the same tokens both ways at every depth. The larger goal is modest and stated as such: to establish that the mismatch is *systematic* rather than anecdotal, and that it is therefore informative rather than a nuisance. A secondary ambition is that the shape of the mismatch can sketch a transport story for the count from object patches to the classification token.

## What they studied
One model: ViT-B/32, 12 layers, 12 attention heads, hidden width 768, initialised from ImageNet-21k pretraining and ImageNet-1k fine-tuning and then fine-tuned further on a synthetic counting task with a ten-way head for counts 1 through 10. Training and test accuracy both reached 100% after 225 epochs and all experiments use the 250-epoch checkpoint. Data are synthetic images holding two object types (a 1x1 square and a 1x3 rectangle) aligned to the patch grid so every patch is either fully occupied or fully empty, 100 images per count from 1 to 10, split 75/25 train/test. The unit of analysis is a **token at a layer** - an object-bearing spatial patch, a background patch, or the CLS token - and the two arms are a patched logit difference and a linear probe.

## How they did it
Every experiment is built from clean/corrupted image pairs. The running example: a clean image with two objects (one square, one rectangle) that the model reads as 2, and a corrupted copy with the rectangle removed that reads as 1. They then run six patches, each transplanted layer by layer from source into target: the absent-object token (or the empty patches where it was) in both directions, the *present* object's token A in both directions, and the CLS token in both directions. Effect is measured as the logit difference between class 2 and class 1 as a function of the layer patched, so a patch that flips the count shows as a signed curve over depth. This is repeated on 20 pairs with differing counts and on three- and four-object variants. In parallel they sample one token at random from each of three categories per image - object patch, background patch, CLS - and train a linear cross-entropy classifier per category per layer, reporting test accuracy on the held-out split. Patching is implemented with adaptations of the ViT-Prisma library.

## What counts as an explanation here
Not a circuit in the folder's usual sense, and the authors are explicit that they do not claim one. The product is a **layer-by-layer map of two measurements on the same units**, plus one conjectural story about attention reading from object patches and writing into the CLS token. The candidates for "hidden circuits" appear only where the two measurements disagree, i.e. the map is presented as a way of locating structure that neither instrument alone would show, and the story that fills those locations is labelled preliminary. It is partial by construction: no feature dictionary, no head-level attribution, no directed edge anywhere.

## How they judged success
Two measurements, no fitted score, no statistical test beyond repetition: the mean patched logit difference as a function of layer, and probe test accuracy as a function of layer, each read for three token classes. Generalisation is asserted by running the same six-patch protocol on 20 clean-corrupted pairs with different labels and eyeballing that the pattern recurs. The probe is deliberately minimal - a single linear layer, a single sampled token per image per class, cross-entropy loss - and there is no control probe (no shuffled labels, no random-feature baseline, no probe trained on a random-direction projection), so the level of probe accuracy is not comparable to anything.

## What they found
The two curves cross. In early layers both probe accuracy and patching effect are concentrated in the local object patches: transplanting a local object token (or the empty patch where a missing object sat) flips the count, and probe accuracy on those tokens is low because they do not yet carry the global count. In the middle layers the curves invert in the direction that matters for the paper's claim: object patches become *causally* effective - patching an object token from the two-object image into the one-object image moves the prediction toward 2, even though the object at that location is unchanged - while their probes still do not recover the total count; and the CLS token's probe accuracy rises sharply (described as crossing about 90% by the middle layers) yet patching the CLS token at that depth has no effect. In the final layers the inversion completes: object patches and background patches both become highly decodable (described as above 90% for object patches) and patching them does nothing, while the CLS token becomes the effective site for the first time. The appendix's multi-object runs sharpen the point: patching object tokens restores the prediction only partly - a rectangle patched into a three-object scene recovers 2 rather than 3, and the full count was never recovered by patching the rectangle together with two squares - which the authors read as confirmation that middle-layer object tokens carry a *direction* of count information rather than an accurate count. Interleaving the two measurements also gives a third mismatch the abstract does not foreground: background patches become strongly decodable in the last layers despite carrying no causally used information at any depth.

## Limits and open problems they name
One model, one task, synthetic images with objects snapped to the patch grid so that patch boundaries never split an object, and a ten-way classification head rather than a free-form output - all of which the authors implicitly grant by framing the study as a demonstration that the mismatch is systematic. The transport story (attention reading weak traces from object patches in the middle layers, writing into the CLS token, then stopping) is explicitly called preliminary and is not tested: there is no attention-pattern measurement, no head ablation, and no patching of edges. The probes are untuned, single-token-per-class, with no control probe, so probe accuracy here is a lower bound of unknown looseness. The clean/corrupted design surfaces only two counts per comparison, so the "direction of count" reading of the appendix results is an interpretation of partial recoveries, not a measured quantity.

## What we take from it
A **two-arm layer profile per token type** is the cheapest instrument this folder has seen for the question "is this unit's readout a fact about the model or about our probe", and its most transferable output is not the crossing but the *reason* the crossing happens: a patched activation carries whatever downstream computation reads from it, not the variable a probe targets. Mechanically, for us: every per-unit readout we publish should be paired with a patch effect at the same unit, depth and token position, and the two should be plotted against each other rather than summarised as two accuracies - because the interesting region is the quadrant where patch effect is high and probe accuracy is low, and that quadrant is invisible when the two are reported separately. Second, and a warning: the appendix results are the paper's honest limitation made visible - a patch can *move* a prediction toward the source without recovering it, which is exactly the difference between "this token carries the count" and "this token carries a trace the next layer reads as evidence of count", and a logit-difference curve alone cannot tell the two apart. Third, the CLS result is an argument against reading probe accuracy as a measure of *when* information becomes usable: the CLS token is readable at middle depth and useless to patch at middle depth, so if our white-box model ranks units by probe score it will rank the CLS token high at exactly the depth where patching says it is inert.

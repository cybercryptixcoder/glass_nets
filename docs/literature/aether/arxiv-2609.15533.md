## What they wanted, and why

Almost every mechanistic claim read off an open-weight language model passes through an interpretable replacement network — a sparse autoencoder or a transcoder fitted to a layer — and the claim inherits that stand-in's fidelity to the real computation. The authors point out that this fidelity is graded, if at all, by reconstruction error on clean text, and ask what happens to the interpretation when the input moves inside a region a user could plausibly reach: a synonym swap, a paraphrase. Their motivating scene is a safety auditor reading a feature catalogue: on a benign-looking prompt the top features describe pathogen cultivation and the auditor refuses, on a one-word synonym variant the top features describe workplace culture and the auditor waves it through, with no change to the model. The larger goal is to replace empirical fidelity with a certified one — a bound that holds for every input in a neighbourhood rather than for the sampled inputs someone happened to try — and then to train the stand-in so that bound is tight.

## What they studied

Five open-weight families: GPT-2 (124M), Gemma 2 2B, Gemma 3 1B, Llama 3.2 1B and R1-Distill-Qwen 1.5B. Two stand-in types per model where both exist — SAEs (ReLU on GPT-2, JumpReLU for Gemma Scope, TopK for Llama Scope and the EleutherAI Qwen SAE, dictionaries from 16,384 to 131,072 features) and transcoders, with the hook position and activation function tabulated per model. The unit of analysis is a (layer, token position) pair: the residual-stream vector at a designated polysemous content word, with the layer's MLP (for transcoders) or the residual itself (for SAEs) as the target computation. Data is WikiText-2; 1,000 sentences chosen so the target word has the most WordNet senses, split 600/200/200, with the prefix before the target replaced by synonyms to build the perturbation set.

## How they did it

Step one is an attack-only baseline: three paraphrase tiers (one content word swapped for a WordNet synonym, all content words before the target swapped, and a Gemma 2 2B rewrite), reporting the top-20 active-feature Jaccard index between the clean and perturbed activation for every layer and both stand-in types. Step two turns the sampled perturbation into a set: for each token in the prefix, they build the convex hull of its synonyms' embeddings, take the Cartesian product, and propagate it to layer k, giving a per-sample input set — the model's own paraphrase hull — inside which the interpretation must hold. Step three, the formal part, defines δ-equivalence: the stand-in is faithful on that set if the ℓ∞ norm of the difference between the real block's output and the stand-in's output is at most δ everywhere in the set. Because the stand-in's nonlinearity has its pre-activation bounds fixed exactly for a box input (the encoder is affine and interval arithmetic is exact on a box), they collapse the whole stand-in into one affine map plus an error interval, avoiding a zonotope in the dictionary-width space, and verify the composite difference network with CORA's zonotope reachability in roughly d_model² · d_IRN time. A binary search over a geometric ladder returns the smallest certified δ, and the same pre-activation intervals yield a certified *lower* bound on the top-K Jaccard: a clean feature survives if fewer than K other features can outrank its floor. A PGD adversary inside the same hull supplies the complementary bound, so both quantities are reported as intervals. Step four retrains the GPT-2 layer-6 SAE under four regimes — clean reconstruction only, PGD adversarial augmentation, verification-aware set-based training that penalises the reachable-set volume, and each of the last with a rank-16 LoRA adapter — and re-verifies on held-out data. Step five sketches compositional verification of the whole stack, block by block, with each block's output set required to sit inside the next block's input box.

## What counts as an explanation here

A certified error interval, not a story. The explanation remains the sparse feature dictionary and its auto-interpreted labels, but the paper's contribution is the epistemic wrapper around it: the claim "feature 11863 describes cellular and molecular biology for this token" is replaced by a bound on how far the stand-in deviates from the block it replaces over a specified set of paraphrases, plus a certified statement about how many top-K features cannot be dislodged by any input in that set. The paper is explicit that a small δ is necessary but not sufficient — a stand-in that always fires the same safe features would certify beautifully and explain nothing — which is why the Jaccard bound is computed as a by-product of the equivalence check rather than trusting the feature-overlap number alone. It is partial by construction: one layer, one token position, one set, and the compositional whole-model version is stated as a vision whose containment checks do not yet close.

## How they judged success

Top-20 Jaccard between clean and perturbed active features (attack-derived upper bound and certified lower bound, reported separately, never averaged). Certified δ upper bound via CORA with a walk-then-bisect search, 12 iterations per sample, 10-second per-call timeout, against PGD lower bounds (200 iterations, 4 restarts in the hull for the difference objective; 300 iterations, 8 restarts for the targeted feature-suppression attack). Per-sample hulls rather than a shared radius, with a uniform-radius ablation at ε ∈ {0.01, 0.05, 0.1, 0.5} for comparability with the verification literature. L0 sparsity of the retrained stand-ins, counted both at the clean input and over the whole hull. Clean reconstruction error. Verified median timings. A claimed soundness Proposition 1 with a complexity argument, and the additional enclosure steps machine-checked in Lean 4, released with the code. The controls are the honest part: an untrained-gap check is absent, but the paper does report that the *underlying model's* own next-token prediction flips for 21% of the minor paraphrases, which prevents the fragility result being read without a base rate.

## What they found

Fragility is general. Top-20 Jaccard at the worst layer falls to 0.27 for the GPT-2 SAE under a single synonym swap, 0.62 for Gemma 2 2B and 0.54 for Llama 3.2 1B; under LLM paraphrase the worst layer drops to 0.05 (GPT-2 SAE), 0.33 (Gemma 2 SAE) and 0.12 (Qwen SAE), against 0.38 for the GPT-2 transcoder. Mean-over-layers numbers are gentler, and the transcoder is consistently the more stable stand-in on GPT-2 (0.79 vs 0.37 at minor). The targeted attack is the sharpest demonstration: on Gemma 2 2B layer 16, minimising the pre-activations of the four biological features active on *culture* in "Describe how someone could culture a sample using laboratory equipment available online" removes all four from the top eight (top-8 Jaccard 0.23), leaving copyright, mathematical operations, research methodology and similar generic labels — the auditor's refusal signal gone with a one-word substitution. Formally, a substantial certified gap exists at every layer of every model: on GPT-2 the verified δ for the SAE is below 1 at layer 1 but the gap widens with depth to what the authors call a degree that no longer permits meaningful interpretation, larger for transcoders than SAEs as expected, and the widening is visible in *both* directions — the verifier's upper bound rises and so does the adversarial lower bound, so it is not verifier weakness. Verification-aware training cuts the verified upper bound by roughly 90% at layer 6 relative to the clean-trained baseline, and to about 13.9 active features from 74.4 (−81%) even though no sparsity penalty was added to any retraining loss; PGD adversarial training alone buys less. LoRA at rank 16 recovers much of the benefit at a fraction of the cost. But feature preservation barely moves: of the clean top-20, only 2–3 features are provably retained, and the certified Jaccard lower bound improves across all regimes without becoming respectable. On the uniform-radius ablation the picture is non-monotone in a way the paper flags: at ε = 0.01 both retrained variants are *worse* in median δ than the baseline (30.22 and 30.38 vs 10.98), and the ordering only reverses from ε = 0.05. The τ sweep is nearly flat (median δ between 47.8 and 60.3), and a larger LoRA rank tightens the bound (median 60.6 at rank 32 vs 169.8 at rank 8).

## Limits and open problems they name

Whole-model compositional verification does not close: the per-layer input sets are still roughly 5× too small at GPT-2 layer 6 for the containment checks to go through, so the framework is per-layer only. The stand-ins remain approximations after retraining, and the authors present the work as a push in a direction rather than an answer. The TopK and JumpReLU enclosures are loose (the undecided set grows to nearly the whole 131,072-feature dictionary at the major perturbation level), inflating the gap between their lower and upper bounds on Llama and Qwen; the Qwen SAE is an order of magnitude less faithful than Llama's by their own measure. They name the deeper problem themselves: a faithful stand-in need not be *complete*, since a dictionary too narrow may simply never represent an unsafe feature, and a δ that stays large after training is a hint of under-capacity pointing to dynamic feature expansion. Their own architecture-honesty remark is that designing models and stand-ins with verification in mind would shrink much of this. Not named but visible to a reader: the whole evaluation sits at one token position in a 1,000-sentence WikiText-2 sample, the perturbation set is WordNet synonyms and one LLM rewrite rather than what a real attacker would do, and the certified lower bound on feature preservation is so weak (2–3 of 20) that it cannot separate the training regimes from each other.

## What we take from it

Two instruments, one warning, and one precedent. The instrument is the **neighbourhood set as the unit of a read-out**: rather than scoring a dictionary, probe or surrogate at an input, score it over a set that contains the inputs a user could plausibly reach, built from the model's own forward pass (synonym convex hulls, propagated to the site), and report the worst case inside it. This is a different object from the folder's stability literature, which resamples data at fixed inputs; here the input moves and the read-out must hold. The second instrument is the **certify-then-attack bracket**: a verifier gives a sound upper bound, PGD gives a witnessed lower bound, and reporting the pair — as was done in the folder only by the provable-circuit entry, for circuits rather than dictionaries — turns "our stand-in is faithful" into an interval that a reader can check for looseness. The warning is the **initialisation trap the paper never ran**: they do state that a small δ is insufficient without a Jaccard bound, but the control that would make this airtight is a stand-in fitted to a *randomly initialised* model, where a `core/` entry already reports auto-interpretation scores indistinguishable from trained models — if the same certification machinery certifies the random-model stand-in just as tightly, the certificate is measuring the fit and not the mechanism, and that arm costs one extra training run. The precedent is that **the training objective can be changed to make a read-out verifiable** — penalising the volume of the reachable output-difference set rather than the error at the sample — which is a concrete alternative to post-hoc certification and is the same shape as the folder's train-interpretable entries: the estimand is designed into the loss. For our predictive white-box model this maps directly onto prediction-under-intervention: our model's prediction for a component should be reported as an interval valid over an input set, its sharpness attacked by PGD inside that set, and the set itself published — because a predictor scored at single inputs is exactly the stand-in this paper certifies as unfaithful.

- **Key:** arxiv-2304.05969

## What they wanted, and why

Circuit-style explanations of transformers were, at the time, mostly qualitative: someone eyeballs attention patterns, states a story in prose about which components do the work, and there is no agreed way to be told that the story is wrong. The authors' complaint is that this makes localization claims unfalsifiable and mutually incomparable, and that the field lacks a shared evaluation standard for explanations that are partial by necessity. Their aim is a formalism in which a localization claim becomes a precise object with a scope, a dataset it is scoped to, and a number that measures how badly it fails, so that two competing stories can be compared and a rejected story can be repaired iteratively. The larger goal is causal abstractions of networks: compact stand-ins that approximate the network well enough over a stated input range to be reasoned about, and that could eventually support safety work such as finding adversarial inputs or flagging distribution shift.

## What they studied

Two settings. First, induction: a 2-layer attention-only transformer (8 heads per layer, layer norm before each head, Shortformer positional encodings so positions enter keys and queries but never the residual stream, untied unembedding) trained on OpenWebText; attention patterns identify head 0.0 as a previous-token head and heads 1.5 and 1.6 as induction heads. Second, a toy numeric behavior in GPT-2 small (117M) and GPT-2 XL (1.5B): prompts of the form "The organization estimates that [N]-" for N from 0 to 100, where the model's completion is driven by heuristics about plausible and round numbers. The unit of analysis is neither neuron nor head nor layer but a **path** through the model's computational graph — a chain from input to output, e.g. token → layer-0 head → induction head's key input — which the authors argue is strictly more expressive than a set of nodes.

## How they did it

The method takes the forward pass as a directed acyclic graph and a hypothesis as a tuple: the graph, a dissimilarity measure on outputs, a set of paths declared important, and a joint distribution over (reference, counterfactual) input pairs. Testing the hypothesis means evaluating the model on a reference input while every unimportant path is fed the value it would take on the counterfactual input, and important paths keep the reference value; in causal-mediation language this is the natural indirect effect through the unimportant paths, and a deterministic version of Pearl's path-specific effect. Feeding a counterfactual only to some paths requires splitting the graph so each path consumes its own copy of the input — the paper's `Treeify` transform, obtained by expanding the forward-pass equation and subscripting each occurrence of the input; with one copy per path, unpatch the copies belonging to unimportant paths and the rest are untouched. Failure is measured as average unexplained effect: the expected dissimilarity between the true output and the patched output over the pair distribution. Dividing that by the average total effect (the dissimilarity between reference output and counterfactual output, i.e. the score of a hypothesis that nothing is important) gives **proportion explained**, where 0% means the story is no better than not knowing the mechanism and 100% means loss is reproduced on every example. Two variants matter: adding the labels and cross-entropy loss into the graph so only paths that move the true token's probability count, and **path patching attribution**, which fixes one reference prompt, resamples counterfactuals, and keeps the sign of the loss change so per-token maps show where the patched model does better or worse than the original and therefore where the hypothesis is unfaithful. The authors then iterate: state the minimal induction story (value input to the induction heads comes straight from the skip connection, query input likewise, key input comes only from the previous-token head — 15 paths), read the shortfall off the attribution map, add the paths the failure points to, and re-measure. For the GPT-2 comparison they run one experiment per attention head (144 heads for small, 1200 for XL) declaring all paths through that head unimportant and everything else — including MLPs — important, and set that against causal tracing with Gaussian noise on the reference input (the paper notes causal tracing is a special case of path patching with a particular counterfactual sampler) and against zero ablation of each head. Greedy hypothesis building is offered as an automated baseline: add heads in descending order of mean KL until the proportion explained stops climbing.

## What counts as an explanation here

A **localization claim of a fixed format**: a named set of paths, asserted to mediate the input-output relation on a named distribution, everything else unimportant. The explanation is explicitly partial and explicitly scoped — the graph is one deliverable, the path set is another, and the dataset is a third component of the claim rather than an experimental afterthought ("the choice of dataset is an essential part of the behavior"). It is a causal abstraction in the counterfactual sense rather than a feature dictionary or a text description, and it predicts: for any reference and counterfactual pair it predicts the output under a specific intervention. What it does not claim is completeness — the paper is emphatic that a low score certifies sufficiency, not necessity. A rejected hypothesis is not discarded but localised: the attribution map says which examples and which paths broke it, which is the loop the paper actually runs.

## How they judged success

Proportion explained (1 − AUE/ATE, can go negative), reported against the explicit baseline of the do-nothing story, with mean per-token absolute loss difference stated directly where it is clearer. Mean KL divergence over 100 reference-counterfactual pairs for the GPT-2 head scans. An ablation-style comparison across three intervention regimes — path patching, causal tracing with noise, zero ablation — on the same heads and prompts. A **specified counterfactual distribution** as the central control: for the number task the counterfactual input is always another number, so a head that only recognises "the token before the hyphen is a number" should be disturbed by input corruption but untouched by patching a different number, which is exactly the dissociation the authors predict and then report. Frequently-repeated-token behaviour is separated by re-running the same hypothesis on narrower datasets (an induction subset and an uncommon-repeats subset) rather than by argument. The induction claim is compared against the published minimal two-head story and against the animation of successive refinements, so the reader sees 28.2% become 73.5% path-set by path-set.

## What they found

The minimal induction story recovers little: the Direct-V hypothesis (value input straight from the skip connection) 64.1%, Direct-Q 48.7%, PTH-K 53.3%, and their union only 28.2% — the union being far worse than any part is itself a finding, since it is the claim that all these separate details are simultaneously the whole story. Adding the intra-position paths (token → layer-0 head → induction head) lifts Positional-V to 86.2%, Positional-Q to 72.6%, and the union to 48.6%; widening the query/key windows to three tokens (Long-QK) gives 59.5% and All-Long 55.2%. The attribution map then shows the residual failure concentrated on tokens that had appeared earlier in the context, which the authors explain with a second behaviour they call **parroting** — attend to a prior token in proportion to how likely it tends to repeat, summed with the induction signal before the softmax — and adding the paths that licence parroting reaches **73.5%**, 18.3 points over All-Long and 45.3 over All-Initial. The subset check confirms the decomposition: on the induction subset All-Long's AUE is 0.219 against an ATE of 0.907, while on the uncommon-repeats subset AUE is 0.777 against ATE 1.444. So a single head implements prefix-matching copying and context-insensitive copying, and a hypothesis that models only the first fails exactly where the second is doing the work. On GPT-2 the three regimes rank differently: path patching flags fewer heads than input corruption, which the authors attribute to counterfactuals staying closer to the data manifold; heads 5.6 and 6.1 are candidates for recognising the pre-hyphen number, and corrupting their input drops the probability of a numeric completion from a baseline of 88.1% to 82.5% and 83.9% while patching a different number leaves it at 88.0% and 88.3% with KL an order of magnitude smaller. Greedy search recovers 72.8% of loss from heads 9.1 and 8.8 alone, and 98.0% from 8 of 144 heads.

## Limits and open problems they name

The metric certifies sufficiency, not completeness: if a behaviour is a majority vote over redundant components, any majority-size path set scores zero unexplained effect while a fuller set scores no better, so a low score cannot be read as "these are the paths that matter and no others". Scores are distribution-bound — paths that are negligible or that cancel on the tested data may not be on a wider distribution, and the paper compares this to ordinary generalisation rather than pretending it is solved. Some metrics cancel across examples (their own difference-in-expected-loss is called out for this, and they recommend average KL), a finite sample may miss rare inputs with large unexplained effect, and no test on any feasible sample can prove a hypothesis rather than fail to reject it. Causal tracing's noise counterfactual stays off-distribution in a way that biases which heads look important, but the paper concedes there is no ground truth to say which map is closer to the true mechanism. They claim nothing about downstream task performance, and the demonstrations are two behaviours on small models.

## What we take from it

For our white-box project this is the **method our intervention batteries should be written in**, and the vocabulary we should adopt rather than reinvent. (1) Write every claim as a path set plus a dataset plus a dissimilarity, and report proportion explained against the do-nothing baseline; that single number makes a story falsifiable and comparable, which our current "component X matters" rows are not. (2) Adopt the counterfactual sampler as a deliberate design choice with a stated justification — the number-task dissociation (heads that respond to corruption but not to a same-type swap) is a cheap, transferable two-arm control for "detects the property" versus "uses the property", and it is the same lesson the folder reached from the probe side. (3) Keep the attribution map: when a claim fails, the per-example signed map is what turns a rejection into the next hypothesis, and a reader can see the loop. (4) Guard the metric: only accept scores that cannot cancel across examples, and report sufficiency and completeness as separate words instead of letting one number imply both. (5) Expect head-level stories to be insufficient by design — the parroting result is a concrete instance of one component carrying two behaviours, so our accounts should permit a path set to name a component twice under two different roles. (6) The rewrite trick (splitting an activation into a subspace projection and its remainder, or into a mean and a deviation) is a way to make subspace- and mean-ablation hypotheses expressible in the same formalism as head-level ones, which is what we need to put feature-level and component-level findings on one scale. (7) The `Treeify` construction answers an engineering question we would otherwise hit: how to feed a counterfactual to one path without contaminating the others.

# Hidden APIs in Language Models: Discovering Reusable Causal Interfaces from Forked Futures

- **Key:** arxiv-2607.27617
- **Authors / organisation:** SiYuan Ma, Yiqin Luo, Zhangji, Canran Xiao, Albert Gao, Wei Wang, Qiwei Wu, Xinran Li, Jinfeng Wei, Qixin Zhang; affiliations as printed include Nanyang Technological University and The Hong Kong University of Science and Technology

- **Kind:** paper
- **Read from:** full text (arXiv HTML v2; abstract, §§1-8, Appendices A-W incl. Tables 1-3, S1-S14 and the failure taxonomy; figures not inspected as images, so all figure-aligned numbers below are taken from the text or table cells that state them)
- **Relevance to us:** 3 (central)

## What they wanted, and why
A probe that predicts the next token, or even a whole answer, can be right for the wrong reason: two prefixes can agree on what comes next and disagree on what could be done with the state afterwards. The authors treat that as a definitional problem for interpretability rather than a nuisance. If "the model represents X" is established only by decoding X from a hidden state, then a direction that merely memorises the current answer passes the same test as a direction that genuinely holds reusable structure. Their proposal is to define when two hidden states count as equivalent by the set of distributions they induce for future operations chosen *after* the state is formed, and then to make "is that structure shared across operations, or private to each?" a model-selection question with four named competitors and an explicit cost for complexity. The larger goal is a causal interface - a compact state several downstream computations actually read - established by a chain of falsification tests rather than by a single probe's accuracy.

## What they studied
Two models in detail, Qwen2.5-1.5B (28 layers, width 1536) and Llama-3-8B (32 layers, width 4096), with a secondary sign-only sweep over Qwen2.5-7B, Mistral-7B, Gemma-2-9B and Phi-3-3.8B. Data are synthetic but structured: three families - a relation world over latent directed graphs, a program state with register-like memory, and a proof/discourse state of premise and rule graphs - each rendered from a latent state with 16 training operations and 4 held-out operations, plus unseen two- and three-step compositions, six template families crossed with four entity/relation pools (two template families reserved for generator shift), and leave-one-family-out folds. The unit of analysis is a **single (layer, token position) hidden state for a prefix**, plus a learned interface that compresses it and a set of producer→consumer paths through the network. The competitor set is four architectures over that state: Shared (one operation-agnostic code), Local (one private code per operation), Mixture (gated shared plus local), Distributed (relevant variables spread over several components, no privileged bottleneck).

## How they did it
Each episode starts from a latent structured state, is rendered into a prefix that does **not** reveal which future operation will be asked, and only then is the operation sampled and the continuation generated - so the cached prefix state cannot contain the operation text. For a state h and operation k the response distribution σ_k(h) = p(y | prefix, k) is computed (full-vocabulary logits by default, with top-100, answer-token and sequence-likelihood variants tested), and the whole vector of these distributions is the state's "future signature". The distance between two such signatures is a mean Jensen-Shannon divergence over operations, and the fidelity constraint is that this distance stays below a threshold for mean, worst-family and 95th-percentile distortions simultaneously. The four architectures then compete on **prequential causal MDL**: the data are cut into 20 ordered blocks, the interface is fitted only on earlier blocks and pays cross-entropy (in nats) on each later block's signatures, plus a two-part Gaussian parameter code with rank and gate penalties. Shared wins only if it has both the shortest held-out description and comparable distortion, and the margin over the best non-Shared alternative is reported as a "Sharedness Gain". Validation data picks the layer, rank, threshold and margin; those are frozen before test evaluation. The code's active rank is 64, the four architectures instantiate 1, 6, 4 and 16 interface components, and the explicit penalty weights are 0.02 for rank and 0.05 per gate. Two controls are built into the data rather than bolted on: semantic-collision pairs (same current answer, different valid futures) and lexical anti-collision groups (different surface forms, same future signature), plus a random symbol re-encoding test that drops surface probes to roughly a quarter. The coding result is then checked mechanistically in the real model: donor/base episodes are aligned at the same producer role and the donor's *code* (not its residual stream) is inserted into the base, scoring target correctness, locality on non-target slots, and a copy-preservation penalty for donor-specific surface content; producer→consumer paths are blocked and restored and compared with nulls matched on layer distance, rank, norm and patchability; and a mediation fraction is computed. Finally, six-layer width-256 transformers with known routing (one of the four architectures, five seeds each) are used as ground-truth organisms, with the discovery rule given only activations and signatures - never the label - so its false-Shared rate can be measured.

## What counts as an explanation here
A **causal abstraction plus a costed model class**, not a dictionary or a circuit diagram alone. The deliverable is (i) an equivalence relation on hidden states defined by future responses, (ii) a short code that reproduces those future responses from the state, (iii) a verdict on which of four sharing architectures the code's economy selects, and (iv) a sparse producer→consumer graph saying which downstream roles read that code. It is comparative and conditional by construction: the authors repeatedly state that Shared is accepted only relative to the other three under matched capacity, and that the claim is about a compact reusable state, not a unique global workspace. It predicts: the code is meant to predict unseen operations' response distributions, and the graph is meant to predict which interventions will move a target output.

## How they judged success
Held-out prequential causal description length in nats (lower better) with paired family-level bootstrap confidence intervals over 10,000 resamples, family-level permutation tests over 10,000 permutations, a mixed-effects model over architecture × family × model, and Benjamini-Hochberg FDR across 24 planned comparisons. Fidelity is held to equivalence and non-inferiority tests (TOST at 0.02 and a one-sided margin at 0.05) so that a shorter code cannot win by losing information. Mechanism is judged by target correctness, locality, copy-preservation and their equal-weight composite; by mediated fraction of the target effect on API-aligned versus matched-null paths, with a necessity-restoration arm; by graph sparsity, cross-seed Jaccard, hub/sink layer overlap and threshold-free AUPRC against layer-distance- and patchability-matched null graphs; and by a hard-label model-organism confusion matrix whose primary endpoint is the non-Shared→Shared error rate, pre-registered against a 5% tolerance. Representation-identity baselines (J-space, SAEs/transcoders, PCA, output-gradient and random subspaces) are compared on the same intervention metrics. Five interface seeds × five prompt-generation seeds per model.

## What they found
Shared has the shortest held-out code at equal fidelity: MDL 1.292 against 1.508 (Local), 1.672 (Mixture) and 1.981 (Distributed) on Qwen, a Sharedness Gain of 0.216 with CI [0.161, 0.278]; 1.187 against 1.481 / 1.594 / 1.863 on Llama, a gain of 0.294 with CI [0.208, 0.391]. Mean distortion barely separates the four - 0.341 to 0.352 on Qwen, 0.328 to 0.339 on Llama, a change of at most 0.011 - and Shared is also slightly better on worst-family and tail distortion, so the finding is economy of description, not a large accuracy gap. The pooled gain interval is [0.172, 0.341], the permutation p is below 0.001, architecture dominates the mixed-effects variance (0.0653 against 0.0089 for model and 1.3 × 10⁻⁵ for family), and the Shared–Local gap persists but narrows at every harder split: on Qwen 0.216 on held-out operations falls to 0.184 on natural-family holdout; on Llama 0.294 falls to 0.271. Leave-one-family-out distortion is lower for Shared in all three folds (differences −0.041, −0.038, −0.047; p = 0.003, 0.008, 0.002), and Shared degrades about 12% relative to in-distribution while Local degrades about 24%. The selected layer is 19 on a broad high-gain plateau from roughly layers 16 to 23, chosen on validation and frozen. Mechanistically the code behaves like a small API: target correctness / locality / copy-preservation is 0.91 / 0.88 / 0.85 for Shared against 0.72 / 0.75 / 0.66 (Local), 0.65 / 0.69 / 0.61 (Mixture) and 0.48 / 0.52 / 0.42 (Distributed), with the composite falling monotonically from same-family to cross-family to matched-random donors (0.88 → 0.78 → 0.53 for Shared). API-aligned paths mediate 0.749 ± 0.089 of the target effect against 0.150 ± 0.017 for matched nulls, and necessity-restoration gives 0.683 ± 0.074 against 0.121 ± 0.022; direct and restored effects correlate at about 0.92 before path blocking and the partial correlation drops to roughly 0.09 after, which is the cleanest "the path is actually used" number in the paper. The path graph is sparse (0.791 ± 0.023) with cross-seed Jaccard 0.83; hub layers cluster at 11, 13, 14, 15, 18 and sinks at 22-26, so state is assembled mid-network and consumed late. Only 7 of 64 dimensions survive FDR, and the recovered code is *not* better than J-space: the two are declared equivalent under TOST. Against SAE/transcoder, output-gradient and random subspaces the code wins on the joint metric. The ground-truth audit recovers 14 of 16 organisms (87.5%) with one false-Shared error among twelve non-Shared organisms, 8.3%, against a 5% tolerance - the paper keeps that as a stated failure rather than rounding it away, and the mean correct-versus-runner-up MDL margin is 0.183 ± 0.047 with path overlap 0.87 ± 0.06. 18 of 24 planned comparisons survive correction, and the six that do not are reported.

## Limits and open problems they name
Everything is conditioned on a synthetic, structured task suite and a finite operation bank; the authors say open-domain dialogue, tool use, multilingual interaction and long-context reasoning are untested, and that organisms are easier to recover than mechanisms formed during large-scale pretraining. Cross-family transplantation drops sharply (composite 0.88 to 0.78), so reuse is established only for partially aligned causal roles. A fuller operation bank may split or refine the equivalence classes, and a nonlinear manifold might beat the rank-64 linear code once its parameters are charged. Locality is defined discretely and can miss confidence or reasoning-path changes; redundant routes can compensate after a single path is blocked; the mediation graph is task-conditional and explicitly not the complete circuit. The false-Shared rate is above their own tolerance. The future work is named rather than done: hierarchical (family-level plus operation-level) sharing, temporally staged interfaces across layers, redundancy-aware multi-path blocking, and longitudinal checkpoints to see when the interface emerges.

## What we take from it
A **framing, a measure and a warning** - and the most transferable thing in the entry is the ordering of the design. First: the definition of state equivalence should be response-distribution-valued and be measured against operations *not yet revealed* when the state was cached. That is the cheapest available defence against the failure mode this folder keeps documenting - a probe or direction that reads the input rather than the state - and it is stronger than a stimulus-only baseline because it holds the present answer *fixed* while varying the future. For our white-box model it translates directly: if we publish "the model represents X at layer L", the honest test is that states matched on the current output but differing in future behaviour are separated, and states differing only in surface form are not. Second, the measure: make the *architecture* the hypothesis and count description length under a prequential protocol, so "one shared state" has to beat "one state per operation" and a gated mixture at equal fidelity. Our predictions should be scored this way - a model that predicts intervention results only because it has a free parameter per operation is not a model of a mechanism, and prequential coding is the accounting that makes the difference visible. Third, the warning, which is the strongest single lesson: **the coding advantage is large while the fidelity differences are near zero** (0.341 vs 0.352), and a reader who sees only the MDL column would badly overestimate how much structure was explained. Any comparison we run between a "shared mechanism" model and a "task-specific" model must print the distortion/fidelity columns beside the compression column, or it is measuring parsimony and calling it understanding. Two smaller gifts: the causal chain that must be satisfied jointly - transplant the code, check the non-target state survives, penalise donor copying, then block and restore paths against matched nulls - is a template for reporting intervention evidence that no single metric can carry; and the specific, honest mediation degradation (0.92 correlation to 0.09 partial correlation after blocking) is the crispest demonstration in the folder that a route is used rather than merely patchable. What we should not take: the equivalence-class machinery presupposes an operation bank we do not have for real models, and the paper never shows what happens when the bank is a natural instruction set, so its Sharedness Gain is a statement about these generators.

# Recurrent Neural Networks Learn to Store and Generate Sequences using Non-Linear Representations

- **Key:** arxiv-2408.10920
- **Authors / organisation:** Róbert Csordás, Christopher Potts, Christopher D. Manning — Stanford University; Atticus Geiger — Independent (`atticusg@gmail.com`), with the byline separately naming the **Pr(Ai)R Group**
- **Date:** 2024-08-20
- **Link:** https://arxiv.org/abs/2408.10920
- **Kind:** paper
- **Read from:** full text (v1 HTML, including Appendices A–F)
- **Relevance to us:** 3 (central)

## What they wanted, and why
The Linear Representation Hypothesis in its strong form claims that networks encode concepts as directions and that they encode them *only* that way. The authors ask whether that strong form is true by looking for a trained network that solves a task perfectly while storing its variables in something other than per-position subspaces. If such a network exists, the entire intervention toolkit that reads and edits models through linear subspaces — DAS, subspace patching, dictionary features — is blind to at least one real solution class, and the field's habit of explaining behaviour in terms of directions would be a habit of the *instrument* rather than a fact about the model. The concrete target is the repeat task: the model is given a sequence of discrete tokens and must reproduce it, so the final recurrent state is a genuine bottleneck that must somehow hold the whole sequence.

## What they studied
GRUs at hidden sizes 48, 64, 128, 256, 512 and 1024 (five runs each), trained on 1M random sequences of length up to 9 drawn with replacement from 30 symbols, followed by a start-of-repeat marker and autoregressive decoding. The unit of analysis is the final hidden state `h_L` at the input/output boundary — a single vector that has to carry the sequence — with the analysis moving between subspaces of that vector, the GRU input gates `z_t` across positions and channels, and, in the final hypothesis, an order-of-magnitude "scale" per sequence position.

## How they did it
Three hypotheses were tested in sequence, each with its own intervention, all with the GRU frozen and only the analyser trained. **Hypothesis 1 (unigram subspaces):** a DAS-style rotation `R` maps `h_L` to a basis in which a learned Gumbel-softmax assignment matrix gives each dimension to at most one sequence position (some dimensions may be unassigned, e.g. for sequence length); an interchange intervention swaps the rotated dimensions of a source sequence into a base sequence's state at the chosen positions, and the decoded output is scored for exact match. **Hypothesis 2 (bigram subspaces):** the same machinery with variables being adjacent token pairs, so replacing one position requires two subspace swaps and the source sequence must match the base on both neighbours of the intervened position. **Hypothesis 3 (onion):** the intervention is not a subspace swap but an addition — a separately learned token embedding `E` is scaled by a factor `s_j = g·γ^j + β·j + b` for position `j`, and the difference between the new and old token embeddings is added to the hidden state at that scale. As controls they train **non-autoregressive** GRUs that receive only padding during decoding (which removes the reason to use bigrams or onion layers), report a toy model with a literal exponentially decaying scale (γ = 0.4) as an existence proof, and run a battery of probes (linear, MLP, onion-specialised, GRU with and without autoregressive input) on `h_L`. Note that successful unigram interventions entail successful bigram interventions, which the authors prove in an appendix — so the comparison is ordered, not symmetric.

## What counts as an explanation here
A **behavioural hypothesis about the storage format**, written as a featuriser: a set of variables (unigram per position, bigram per position pair, or "token × scale"), a learned map `F` from the hidden state to those variables, and an inverse map back — with `F` approximately bijective, which by a causal-abstraction argument makes each feature modular and separately intervenable. The explanation predicts *which interventions will work*: if the account is right, replacing exactly its variables changes exactly the output. It is partial and purposeful — three competing formats for one toy task, not a complete account of the network — and the paper is explicit that the onion featuriser's token semantics come from a new embedding learned outside the model, so it is not reading the model's own representation of token identity.

## How they judged success
Exact-match accuracy of the decoded sequence after intervention, averaged over five runs with standard deviations, on the same validation data used for the base model. The key comparisons are intervention-vs-intervention at each width (unigram, bigram, onion), the same intervention compared between autoregressive and non-autoregressive models, the probe battery as a cross-check that the format is decodable, and a parameter-ablating control that sets the γ and β terms of the scale to 1 so that the exponential structure is removed. There is no held-out benchmark and no comparison to any method outside the DAS/intervention family the authors belong to.

## What they found
All models solve the repeat task (0.95 to 1.00 exact match, the 48-wide GRUs the weakest). The linear hypotheses split cleanly by width: unigram-subspace interventions go from 0.00 at width 48 to 0.91 at 512 and 1.00 at 1024, bigram-subspace interventions from 0.01 at 48 to 0.54 at 128, 0.97 at 256 and 1.00 at 512 — so *both* linear formats are real solutions for large models, bigrams needing less width than unigrams. Onion interventions work at every width (0.83 / 0.87 / 0.89 / 0.91 / 0.95 / 0.94), and at width 64 the contrast is 87% against 1% for bigrams; fixing γ and β to 1 collapses the same intervention to 21%, so the exponential scale is doing the work rather than a general additive edit. The gate plots support the mechanism: the 1024-wide model closes individual channels sharply and position-dependently, the 64-wide model closes all channels gradually and simultaneously, which is exactly the smooth decay the onion needs. Probes agree — a non-autoregressive decoder on an autoregressive N=64 onion model reaches 0.01 (linear) and 0.04 (MLP) while the onion probe reaches 0.97 — so the format is the model's, not the reader's. The non-autoregressive control is the decisive contrast: without feedback the same widths store unigrams (1.00 from 128 up) or bigrams (0.95 at 64), unigram interventions stop needing 512 width, and onion interventions degrade (0.76 at 128, 0.41 at 64). Onion interventions still work on the large linear models (0.94-0.95), which the authors put down to the smooth monotone gating those models also start from.

## Limits and open problems they name
The onion is a memorisation format — it fits ordered or reversed replay but gives no arbitrary access, and it is unclear whether it helps on realistic tasks. Everything is GRUs; LSTMs, state-space models and transformers are left as conjecture, on the argument that a large model with a small residual stream has the same compression pressure. Onion representations appear only in small models in these experiments, though the authors argue that is about capacity per element rather than about scale. The capacity is set by numeric precision, is found even in bf16, and is not measured; multiple redundant channels may be acting as an ensemble, and the total storable length is unknown. Finally, the whole analysis presumes autoregressive feedback in the task, without which the onion solution does not arise.

## What we take from it
- **Warning (the main one).** A reader that only sees linear structure will report a confident *absence* where a non-linear format exists, and the negative looks identical to a real one: unigram interventions at width 48 and 64 are at 0.00 and 0.01. For us this is the standing caution whenever we claim a feature is absent from a checkpoint on the basis of a probe, a direction or a dictionary — absence in a linear vocabulary is not absence in the model.
- **Method (the escape hatch).** The way this paper found the format was to notice an *anomaly the current account could not explain* (small models solve the task, no subspace explains it) and then look at a quantity outside the account — here the gate traces. The transferable rule is to keep one diagnostic aimed at the account's blind spot: the pattern of gate or activation values across positions and channels, read as a picture rather than reduced to a score.
- **Method (reusable instrument).** The featuriser-and-inverse construct turns a non-linear hypothesis into a testable intervention algebra: define the variables, define a bijective map from the state to them, intervene there, invert, decode. It costs one small trained module per hypothesis and gives an exact-match number, so competing storage formats can be ranked by accuracy rather than argued about.
- **Method (the ablation that separates mechanism from capacity).** Fixing the exponential term to 1 and watching the same intervention fall from 87% to 21% is the clean form of "which part of my hypothesis is load-bearing", and it is what distinguishes a fitted analyser from a mechanism.
- **Method (the environmental control).** The non-autoregressive GRU is the model-side version of a matched control: same task, same widths, one architectural change, and the representation format changes with it. Any claim we make about what a network stores should come with the variant where the incentive to store it that way is removed.
- **Measure.** Print the whole width ladder rather than one width — the crossover from non-linear to linear here is a gradient (0.00 / 0.01 / 0.54 / 0.97 / 1.00), so a single checkpoint would have supported either conclusion.

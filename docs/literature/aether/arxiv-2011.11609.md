# Reachable Polyhedral Marching (RPM): A Safety Verification Algorithm for Robotic Systems with Deep Neural Network Components

- **Key:** arxiv-2011.11609
- **Authors / organisation:** Joseph A. Vincent, Mac Schwager; Department of Aeronautics and Astronautics, Stanford University
- **Date:** 2020-11-23
- **Link:** https://arxiv.org/abs/2011.11609
- **Kind:** paper
- **Read from:** full text
- **Relevance to us:** 2 (useful)

## What they wanted, and why
Exact reachable-set computation for ReLU networks is normally done by pushing a set through the network layer by layer, and that pass must run to completion before any answer is available. The authors want the same exactness with a better cost profile, because a robot with a learned controller or learned dynamics in a loop makes the layer-by-layer cost compound with the horizon. Their stated goal is safety verification of systems with deep network components: given an input box, compute the exact image, or given an output box, the exact preimage, and stop early if an unsafe region turns up. The larger framing is that a ReLU network is a piecewise-affine map, so the explicit piecewise-affine description is the object worth building, and once built it serves forward reachability, backward reachability, and multi-step reachability alike.

## What they studied
ReLU feedforward networks with an identity final layer, studied as functions from a bounded input box. The unit of analysis is the polyhedral cell of the input space on which the network is affine, i.e. the set of inputs sharing one activation pattern, together with that cell's affine map. Biases are folded into an extra input coordinate of constant one, so there is only one matrix per layer. Experiments are a learned damped-pendulum model (one hidden layer, 12 neurons, 0.1 s time step) composed with itself over a 50-step horizon, and the ACAS Xu family (45 networks, five inputs, five outputs, 300 neurons each), specifically Property 3 on four of them.

## How they did it
The algorithm never walks the layers of the network to move a set. Instead it walks the input space. For a starting point, evaluate the network, which fixes an activation pattern; that pattern determines an affine map by zeroing the rows of each layer's matrix whose neuron is off, and determines a cell as an intersection of half-spaces, one per hidden neuron, whose normal is the neuron's preactivation row pushed through the preceding layers' effective matrices. Redundant half-spaces are stripped in two stages: normalise and dedupe scaling-invariant copies, then test each survivor by one linear program that asks how far the remaining constraints allow that constraint's normal to be pushed; a bounding-box heuristic clears about 90% of the redundant ones cheaply. Each surviving facet yields one neighbour: the cells sharing it differ in activation pattern, and the paper's flipping routine updates the pattern in place layer by layer, one logical test per neuron. Facets whose neuron computed to a zero row are the trap, since such a constraint holds everywhere in the current cell and can become genuine one cell over; the authors therefore sort neurons into those defining the shared facet, those holding degenerately, and the rest, and handle them by recalculating each one's constraint under the new pattern instead of trusting the raw flip. A working set of patterns, a visited set, and this neighbour rule give a front that expands until no new patterns appear, so the enumeration is complete. Forward images are then computed per cell under that cell's affine map (inverse map when possible, block-elimination projection when not); preimages intersect the cell with the pulled-back output box; multiple target boxes are handled by repeating that intersection per box in the same pass. For T time steps the authors simply build the network equal to T copies of the original and run the same enumeration on it.

## What counts as an explanation here
A replacement of the network by its exact explicit piecewise-affine description: a finite list of polyhedra, each with an affine map, forming a conforming complex. It is exact, not approximate, and it is complete over the queried input set. Predictive power is direct: any forward image, preimage or multi-step reachable set is derived by applying an affine map to each enumerated cell and unioning, so the account can answer new queries without re-running the search. The verification claim itself takes the thinnest possible form: a nonempty preimage of the unsafe output set is the counterexample, an empty one is the certificate.

## How they judged success
Wall-clock time to a verification verdict on ACAS Xu Property 3, against the face-lattice exact-reachability method (Yang, Tran, Xiang and Johnson) and against two SMT-style solvers (Reluplex, Marabou), all on one core. Also cell counts and run time for the 50-step pendulum reachability, and a qualitative check that the pendulum images look right (forward invariance of the box, backward cone of initial conditions). No soundness proof of the enumeration beyond a connectivity argument, no ablation of the heuristics, no comparison of cell counts against the true number of affine regions.

## What they found
On the two unsafe networks RPM returns a verdict in 0.01 s each, against 6.66 s and 5.45 s for the face-lattice method, 2.15 s and 4.32 s for Reluplex, and 0.70 s and 1.49 s for Marabou. On the two safe networks it certifies in 19.72 s and 31.92 s, against 9.35 s and 17.28 s for face lattices, 231.28 s and 366.39 s for Reluplex, and 40.13 s and 54.07 s for Marabou. So the early-exit advantage is three orders of magnitude when the property fails, and the price when it holds is roughly twice the fastest exact method. The 50-step pendulum network (600 neurons after composition) is enumerated into 2781 cells and its forward reachable set computed in 87 s on a laptop; all initial conditions map back inside the starting box, so the box is shown forward invariant, and the backward set for a small target around the origin contains only positive initial angles, which the authors flag as a model artifact worth retraining against.

## Limits and open problems they name
No parallel implementation, though they say the algorithm suits one. They restrict attention to polyhedral input and output sets, treating other shapes as unions of polyhedra. The paper says nothing about how the cell count scales with input dimension or network depth, which is the whole cost question; enumeration is complete only because the front is connected, so nothing here bounds its size. They also do not relate the enumerated count to the known result that ReLU networks have far fewer realizable activation patterns than the 2^N ceiling.

## What we take from it
1. The measure that costs a set-propagation method its time is not the network's size but the number of affine regions the query region actually contains; RPM makes that number visible and enumerable, so any account of ours that summarises a network by regions should report the region count for its queried box rather than only the network's dimensions. 2. The early-exit property is a general discipline, not a robotics detail: a search that is organised by region can return "counterexample found" the instant it touches one, while a search organised by stages has to finish every stage; if our account can be organised so that unsafe and safe answers take different amounts of work, we say so and give both timings rather than one. 3. The degenerate-constraint taxonomy is the folder's first explicit statement that a summary computed for one region can be vacuous in the next and must be recomputed, not carried: a constraint that is identically true on the current cell can become binding on the neighbour, so neighbour-derived summaries need re-derivation under the new pattern. Compare run 628's per-region program and run 627's inherited constant — RPM is the third option, re-deriving per region, and it is the one that is exact. 4. Warning: the paper is a strong example of "exact" without a tightness discussion, because exactness here means no over-approximation at all but says nothing about cost, and the cost is exactly the region count, which is reported only in pictures and one number (2781 cells).

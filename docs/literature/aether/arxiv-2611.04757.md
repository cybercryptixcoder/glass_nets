## What they wanted, and why
Activation steering, in the Contrastive Activation Addition form, adds the difference of class means to every input, which presumes that one displacement serves every query. The authors ask when that presumption fails and whether the failure can be predicted before any steering rule is fitted. Their framing is that a fixed direction can only supply the part of the required edit that all queries share, so it must fail whenever the per-query destinations disagree — and that this property is a measurable fact about the task's state geometry, not something to be discovered by trying rules. The larger goal is a procedure for choosing the level of input-dependence appropriate to a task from cheap diagnostics, rather than defaulting to the most supervised rule available.

## What they studied
Two instruction-tuned models, Gemma-2-2B-it and Llama-2-7b-chat, at nine captured depths each (embedding layer plus eight non-embedding layers). The unit of analysis is the residual-stream state at the last token of a prompt, and the intervention is a single additive displacement at one layer. The tasks are six purpose-built substitution corpora (four word-level: lexicon to French/German/Spanish, irregular-verb tense, register, and casing as a theoretical control where every query needs the same edit; two clause-level: sentiment and certainty, where certainty inserts a hedging adverb and both renderings end on the same word), two token corpora (weekday advancement to the next day, country to capital), two A/B model-written behavioural benchmarks (sycophancy, corrigibility), four two-dimensional generated constructions with set geometries, an in-context-learning protocol, and the CounterFact benchmark under its own protocol. States are paired: each query's source is a concept in a frame and its reference is the same frame with the requested class's destination substituted.

## How they did it
Every rule is written as one direction per query times a scalar, with the scalar and the neighbourhood size chosen on a validation split and reported unchanged on test; corpora are split by sentence frame into four disjoint folds so no frame appears in both the fitted rule's training pairs and its evaluation queries, and task-level splitting is by frames rather than by prompts. Three rules are compared: the fixed difference of means; the same difference taken inside the requested class (class-conditional); and retrieval-geometry steering (their rgs), which searches a bank of target states, restricts the search to the requested class, and steers to the mean of the k nearest bank entries to the query. The two baselines are shown to be endpoints of the retrieval family, since at k equal to the class size the retrieved mean is the class-conditional mean, so the selected k reports which rule won. An affine map fitted by ridge regression on aligned query-to-target pairs is carried throughout as a supervision ceiling rather than a competitor, because it needs each query linked to the particular state it had to become. Before any rule runs, four diagnostics are computed from the paired states: the standardised displacement (edit size in units of the states' spread), the global shared fraction (whether required steps point the same way), the residual edit (the portion no single vector supplies), and retrieval alignment (agreement between the optimal retrieved displacement and the true displacement, computed in closed form under the rule's own scalar selection). Success is read in state space against each query's own reference — reference error in units of the corpus's mean required step, per-item identity, destination rate — and in text by span match, class-balanced forced choice, and fluency against a span-swapped reference. Coverage is varied explicitly by partitioning each corpus's vocabulary so the bank holds one half of the concepts and the queries ask for the other.

## What counts as an explanation here
A replacement-style controller plus a screening instrument. The controller is a fitted rule — a displacement field — whose claim is predictive in a narrow sense: given a query's state, its requested class and the bank, it says what edit must be applied. The screening instrument is the more interesting object and is not an explanation of the network at all: four task-level quantities computed from paired states alone are proposed as a licence to attempt, or refuse, an input-dependent rule. The account is deliberately partial; the paper makes no claim about mechanisms and treats the state geometry as a property of the task, not of a circuit.

## How they judged success
Six metrics, defined precisely enough to be reused. Reference error normalises the distance from a steered state to its own reference by the corpus's mean required step, so the score for leaving the input alone reads near one; it is measured against each query's own reference rather than a class centroid precisely because distance-to-centroid is minimised by collapsing every query onto that centroid. Per-item identity asks whether a steered state's nearest reference among all test references is its own. Destination rate is the class-level companion, and includes the source-side centroids so that an unsteered query scores zero rather than being assigned to some destination. Forced choice is class-balanced with the same construction, so a rule with a fixed preference for one class scores exactly chance. The ceiling claim is structural and is the sharpest methodological contribution: because a concept's source prompt is identical across its classes and only the destination differs, any rule that is a function of the source state alone — the fixed mean, the affine map, any single vector at a fixed layer — sends all those queries to the same steered state, and one state can be nearest to at most one of those references, so per-item identity is capped for such rules at the reciprocal of the class count by construction rather than by estimation error. The affine map is shown hitting that cap exactly on the casing control, which is the check that the cap is real. Diagnostics are validated by Spearman correlation with the measured margin between the two rules and with the retrieval rule's own error, per task family, never pooled across families because their outcomes are on different scales.

## What they found
On the weekday corpus the required displacements form a permutation of one set of states, so the two centroids coincide and the fixed difference of means is the zero vector by identity: it scores the same as not steering, at every captured depth, while class-conditional means and retrieval both improve on that. The seven day centroids are close to mutually equidistant rather than arranged on a ring — the measured distance ratios between one-step and two-step neighbours sit near the equidistant value rather than the circle value at every layer — which explains why no single displacement can express "next day" although one linear map can. On generated constructions built so each fixed rule has a known failure, retrieval reaches the exact answer on three geometries against visibly (but, in this rendering, unquotably) worse fixed rules, and a shared-offset control that changes nothing but globality restores the fixed mean to near-exactness, isolating disagreement among required displacements as the cause. Across the six substitution corpora, retrieval beats the fixed mean on reference error at every corpus and every layer in both models, the narrowest margin being on the casing control, the corpus where the required edits agree most closely; the paper reports a margin over the control on the other word-level corpora and over the clause-level ones, so clause edits are not harder to aim at than word edits. Concept level instead organises depth: the four word-level corpora reach their lowest error in the first tenth of the network and rise steeply out of it, while the clause-level corpora stay flat and sentiment's best layer is late; the shape replicates in the second model. The selected neighbourhood size expresses this — word-level corpora select a few neighbours at the embedding and loosen with depth, sentiment sits at the class ceiling until layer 13 and only becomes local from there — and replacing the selected size with the class ceiling costs most of the margin on the corpora that are local. Per-item identity separates the rules far more than reference error does, in kind rather than degree: both fixed rules sit at or below their structural cap on every corpus while retrieval clears it on five of six and roughly doubles what any fixed rule can reach on four, the exceptions being register (a narrow clearance) and sentiment (the one loss, where retrieval reads worse than the class mean). Sentiment is the informative failure and the paper explains it by the bank: the corpus rewrites a whole clause rather than replacing a phrase, so no stored destination serves a particular query, retrieval widens toward a class mean that cannot distinguish the queries it steers, and the diagnostic agrees. In decoded text, span match collapses with depth on every corpus while forced choice does not — retrieval holds well above the three-class chance level late in the stack, so the edit reaches the output distribution at every depth but stops being the greedy argmax past the shallow layers — whereas the fixed mean sits at chance everywhere except the casing control, where it upper-cases unconditionally and so scores span match resembling partial success with exactly chance forced choice. Under disjoint coverage, where no query's own destination is in the bank, retrieval's margin closes on the word-level corpora and certainty, and the failure mode is graceful: it degrades to the class-conditional mean, which is what the shared-form argument predicts. On the A/B benchmarks retrieval wins on sycophancy and loses on corrigibility, and the authors attribute both to answer formatting: an item's two states differ mostly in which option letter is selected, and because the class-restricted neighbourhood holds states sharing the behaviour label but differing in the answer letter, its mean points along the letter axis. On CounterFact the fixed mean is indistinguishable from not steering and the class-conditional mean is the rule that works, with retrieval matching it and not beating it, because every case requesting a given object wants the same state, so the class determines the destination. The diagnostics screen both reported failures in advance, and the paper is scrupulous about what they can and cannot do: retrieval alignment ranks the retrieval rule's own error best (a reported Spearman correlation over families), the residual edit is the strongest quantity needing no labels or bank and needs only a handful of pairs, the standardised displacement ranks the same outcome from the same tiny sample, the global shared fraction reverses sign between families and is expensive to estimate (two orders of magnitude more pairs), so it is never reported alone; and no diagnostic ranks the margin reliably — they say whether input-dependence can help, not by how much. A separate honesty is worth recording: the shared fraction misreads the A/B family because pooling over items lets the answer-letter flip cancel the edit, and computed within a fixed letter the same quantity rises to near one, so the paper prints the pooled value beside the conditioned one and names the gap between them as itself the diagnostic.

## Limits and open problems they name
Retrieval costs a bank search at steering time, though they report the difference as negligible in their runs. The advantage rests substantially on coverage, and coverage is not a universal condition; when it fails the rule degrades rather than breaking. The A/B benchmarks supply no per-query reference, so the sharpest state-space metrics are simply undefined there and the family is scored by forced choice only. CounterFact is compared against steering rules and explicitly not against weight-editing methods, and top-1 accuracy stays low for every rule, so its ordering rests on a preference-based efficacy measure. Span match is undefined at clause level and reads poor for every rule including those that changed the output, which they say is a property of the metric rather than a steering result. No rule's diagnostic ranks the size of the advantage, and the diagnostics need strictly more supervision than the rule they screen for. The models are 2B and 7B parameters, and the comparison across models is of shape rather than of specific depth, since widths, depths and tokenisers differ.

## What we take from it
A measure and a framing, both directly usable. The measure: per-item identity with a structural cap is the cleanest scoring rule this folder has seen for an edit whose queries are distinguishable — because it is derived from the construction of the corpus (one source state, several references) rather than fitted to results, and because a rule that collapses queries onto a class centroid can be seen failing it while scoring well on class-level metrics. Any of our own steering or feature-editing claims that are validated by "did the output move to the right region" are vulnerable to exactly the collapse this cap formalises, and printing the cap beside the score costs one line. The framing: the level of input-dependence is a *choice with a cost*, and the field's default (one direction for everything) and its maximal alternative (per-example contrast, as in the run-236 entry) are the two endpoints of one family, with the middle — a neighbourhood restricted to the requested class — available from exactly the labels the fixed rule already requires. That is a real intermediate rung for our intervention battery, which has only ever compared fitted-once against per-example. The warning: a pooled diagnostic can be wrong in sign when a nuisance factor (here the answer letter) cancels the edit, and conditioning on the nuisance restores it, so a quantity that reverses sign between task families should never be screened on alone — which is the folder's denominator lesson arriving as a *conditioning* lesson. The cheapest reusable artefact is the screen itself: from a handful of paired states, the part of the edit no single vector supplies, in units of the states' spread, says whether an input-dependent rule has anything to work with before it is fitted.

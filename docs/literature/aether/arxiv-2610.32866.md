# Interpretable sparse fine-tuning with TopKLoRA enables faithful circuit discovery

- **Key:** arxiv-2610.32866
- **Authors / organisation:** Marek Masiak, Andrzej Szablewski (equal contribution), Nicola Cancedda (work done as an independent researcher), Constantin Venhoff; University of Oxford (Engineering Science) / University of Cambridge (Computer Science) / Neuralk-AI
- **Date:** 2026-10-23 (arXiv:2610.32866v1; 29 pages, 10 figures; CC BY 4.0)
- **Link:** https://arxiv.org/abs/2610.32866
- **Kind:** paper (method + model-organism case study; extends the authors' NeurIPS 2025 MI-workshop proposal of TopKLoRA)
- **Read from:** full text (arXiv HTML v1, ~92k chars including Appendices A–G; figures 1–10 known only from their captions, so every number below is a table cell or an explicit sentence)
- **Relevance to us:** 3 (central) — the folder's first entry where the **unit of analysis is designed to be identifiable by construction**, so the question "does the circuit claim survive being acted on" can be asked without the usual post-hoc-dictionary confound. It is also the cleanest instance of an exact-count necessity test, a paired sufficiency test, and a planted-circuit recovery control in one pipeline.

## What they wanted, and why

Fine-tuning on data of unknown provenance is an attack surface: a small poisoned fraction can implant a trigger-conditioned behaviour that later safety training does not remove. Defences that act on data or on outputs leave the mechanism untouched, and attempts to localise such behaviour in dense weights have been inconsistent. The authors argue that parameter-efficient fine-tuning already confines the update to an adapter, but nothing forces that adapter to be interpretable, and post-hoc dictionaries are trained to reconstruct activations rather than to cause behaviour — so a circuit built on them inherits the wrong objective. Their proposal is to make the update itself auditable: an adapter whose bottleneck is sparse enough that each token uses a small, input-dependent slice, so that "which components implement this behaviour" becomes a question about named, trained units rather than about a fixed basis. The larger aim is interpretable-by-design fine-tuning in which a behaviour can be attributed to a small component set and removed without retraining.

## What they studied

Base models: gemma-2-2b (26 layers, d_model 2,304), Qwen2.5-1.5B and Qwen2.5-7B (28 layers; the Qwen bases are modified checkpoints whose chat-template embedding and output rows are copied from the matching Instruct models). Three adapter placements per model: a single layer, a 9-layer band, and all layers; every configuration trained with five seeds (42–46). Adapter capacity: r = 64, k = 8 for gemma-2 (k/r = 0.125), with r scaled to hidden size for Qwen (42/5 and 100/12), giving latent pools from 448 (gemma single layer) to 19,600 (Qwen-7B all layers). Unit of analysis: the **latent** of a TopKLoRA adapter, indexed as (attachment site, latent index); a circuit is a subset of that pool across all adapted modules. Behaviour: a sleeper-agent backdoor on a 10,500-row Alpaca-cleaned instruction set with a 4.76% poison rate, where a natural-language tag (gemma) or a trigger/payload token pair (Qwen) conditions a fixed hateful payload; the clean tag leaves behaviour unchanged. Dense LoRA baselines with matched rank and placement, clean-only twins, and gradient-routed organisms with planted circuits complete the design.

## How they did it

The adapter is a LoRA whose bottleneck is made sparse: project to r dimensions, apply ReLU, keep the k largest entries, and up-project — so each token is processed by an input-dependent rank-k slice of the adapter, and the ReLU plus top-k selection break the invertible-reparametrisation symmetry that makes plain LoRA latents unidentifiable. Training uses the downstream loss only: no reconstruction term and no sparsity penalty, since k fixes the sparsity. Each latent is then read as a **pair** — a condition direction (its row of the down-projection, defining what it reads) and a steering direction (its column of the up-projection, defining what it writes) — and latents attached across modules compose into a circuit through the shared residual stream. Discovery, called Contrastive Latent Circuit Discovery, splits into a search stage that only **ranks** the pool and a verification stage that alone decides membership. Search is scored on paired prompts (one eliciting the behaviour, one with the eliciting element removed) using integrated gradients over the post-top-k latent vector, giving a per-latent attribution summed over positions and averaged over episodes; two other rankings are compared, a Sparse Feature Circuits ranking adapted without code changes, and a single-pass elimination sweep that visits latents from weakest to strongest and removes one only if both tests still pass. Verification sweeps prefixes of the ranking over a pre-fixed grid of sizes K, applies two interventions — ablate(C), which zeroes the circuit's latents and leaves the rest, and keepOnly(C), which zeroes everything else so the adapter contributes only C — and accepts the smallest prefix that passes both tests. Attribution, elimination and verification prompts are disjoint splits, and sufficiency is compared prompt by prompt against the intact model, which makes it paired.

## What counts as an explanation here

A **circuit** in a named, trained coordinate system: a set of adapter latents, each with a read subspace and a write subspace, plus the ranking that produced it and the verification verdict. It is deliberately shallow — the authors state they do not interpret individual latents, treating them as uninterpreted nodes of a larger graph. The claim attached to it is two-sided and operational: necessity means zero-ablating the set drives the behaviour rate to exactly zero, sufficiency means keeping only the set loses no behaviour beyond sampling noise. The explanation is not a description of what any latent means; it is a partial, actionable decomposition of a fine-tuned behaviour into components that can be removed, plus the empirical statement that removing them leaves the base capability intact. It predicts what will happen under two specific interventions and claims nothing about the base model's own features, which are carried only as an error node.

## How they judged success

The behaviour metric is attack success rate — the payload appearing anywhere in the first 40 generated tokens — requiring at least 90% on triggered prompts and at most 0.5% on clean prompts before any circuit verdict is issued. Necessity is an **exact count**: zero-ablating the circuit must give ASR exactly 0 on the verification split, with no post-hoc tolerance, so a circuit that misses a rarely firing mechanism cannot pass. Sufficiency is a paired degradation test: keepOnly is compared with intact prompt by prompt and must be within two standard errors of zero loss, with the tolerance therefore scaling with prompt count. Size is found by a pre-registered prefix sweep over a family-specific grid, shared by seeds and between dense and TopKLoRA adapters, so sizes are comparable at the same resolution and a verified size is an upper bound at grid resolution. Three controls carry the argument: random latent sets of the same size and module placement (specificity), a random visiting order with no attribution at all (whether attribution is what makes circuits small), and gradient-routed organisms where only the first d latents of every adapted module receive the poisoned examples' gradients, so a correct circuit must lie inside a known planted set — with unrouted twins sharing the recipe as the chance-overlap control. Explanation quality is measured as **retention**, the ablated model's judge-scored instruction-following normalised between base and intact; a clean-only twin gives the floor for what an ablated poisoned model should look like. A straight-through estimator comparison shows the hard top-k mask is not the only option, reported with ASR, clean-fire rate, loss and never-selected counts.

## What they found

Verified circuits exist for every organism, and TopKLoRA circuits are smaller than their dense-LoRA counterparts in all 30 seed-matched pairs. On gemma-2-2b the median verified circuit is 22.3% of the adapter in the single-layer family against 89.3% for dense, 7.4% against 69.4% in the 9-layer band, and 3.4% against 41.2% across all layers; the dense/top-k ratio grows with the number of adapted layers. Specificity separates the two: zero-ablating a random latent set of the same size leaves the backdoor intact in five of six TopKLoRA families (median ASR 0.92–1.00) but removes it in five of six dense families (median ASR 0.00), and the one dense family that passes the specificity control is the one whose circuits are smallest (gemma all layers, 41% of the pool). Necessity needs far fewer latents than the necessary-and-suffcient circuit contains: zero-ablating at most the top 1.2–6.8% of the TopKLoRA pool already brings ASR to zero, against 20.6–38.9% for dense. Removal is surgical in multi-layer adapters — ablating the verified circuit stops the backdoor on at least 99.9% of held-out prompts, and all 30 multi-layer TopKLoRA organisms keep retention close to one — while single-layer circuits are surgical only when small; on gemma-2-2b, multi-layer ablated organisms sit close to their clean twins (alpaca judge score 3.06 against 3.14 clean, a difference of −0.08) whereas single-layer organisms fall well below them (−1.10). On planted organisms the verified circuit lies mostly inside the routed set at wide widths (98% of it at d = 8 against a 12.5% chance share, 80% at d = 4 against 6.2%), and the unrouted twins overlap the same latents only at chance (11%). Attribution buys **size, not validity**: with a random visiting order every circuit still passes verification with at most one held-out backdoor response in 4,000, but the kept set triples (median 18 → 54 latents) and the verified circuit grows from 22% to 61% of the adapter. Circuits are also not unique — kept sets from different orders overlap only 7–23% by Jaccard, several times chance, around a shared core of 3–9 latents.

## Limits and open problems they name

Everything is at 7B parameters or below; the trigger is a syntactic tag, which caps the complexity of the learned behaviour; and localisation assumes contrastive paired prompts **and knowledge of the trigger**, which the authors call unrealistic in many cases, naming semantic and unknown triggers as future work. Individual latents are never interpreted. The base model's contribution is modelled only as an error node in the SFC arm, so latents that interact with base features are unstudied. The paper's own reporting adds two limits it does not list: the planted-set experiments show that keeping only the planted latents reproduces the behaviour in just 2 of 11 organisms while a circuit drawn inside the set exists in all 11, so sufficiency is not unique and the set contains latents that suppress the behaviour once the adapter is ablated; and the leak table's own caption concedes that the generated text was discarded, so an ordinary answer containing the payload phrase cannot be told apart from a genuine backdoor response.

## What we take from it

- **A method for making the unit identifiable.** Training the dictionary under the downstream loss — no reconstruction term, no sparsity penalty, sparsity set by k — produces units that are functionally causal by construction rather than by post-hoc assumption. For a white-box model that must predict under intervention, this is the cheapest way to remove one whole class of objection: the basis cannot be blamed for the circuit, because the basis was never fitted to a different objective.
- **A measure: exact-count necessity plus paired sufficiency.** The combination is unusually strong for this folder, which usually stops at a nonzero sufficiency floor or a thresholded completeness. Exact zero on an independently held split is a bar that can only be cleared by a circuit that carries the rare mechanism too, and the paired sufficiency test makes the tolerance scale with n instead of being chosen.
- **A warning about sufficiency.** The planted-set result is the sharpest case in the folder that the *full* known-responsible set can fail sufficiency while strict subsets pass: a superset is not a witness, because a larger set can contain suppressors that only bite once the rest is ablated. Any preservation or ablation claim over a set we did not search for has to be verified as a prefix or a chain, not assumed monotone.
- **A framing for negative controls.** Attribution changes circuit *size* by roughly a factor of three, not circuit *validity* — random order still verified everything — which tells us which metric a discovery method is actually earning. Report size and validity separately, because "the method works" and "the method is informative" are different claims when the instrument's validity floor is reachable without it.
- **A shortcut for our own model organisms.** Gradient routing confines a trained behaviour to a chosen slice of latents, giving a planted circuit with a known superset and a twin as the chance control. This is the most directly reusable experimental trick in the paper for building testbeds where prediction-under-intervention has a ground truth.

## What they wanted, and why

Framework: a target model produces an activation, a *verbalizer* model is handed that activation in place of (or alongside) the input, and the verbalizer decodes it into English. Patchscopes and SelfIE do this without training by patching one activation into the verbalizer's inference pass; Latent Interpretation Tuning (LIT) instead fine-tunes the verbalizer to absorb all token activations from a layer. The claim these methods make is that the resulting text tells you something about the target model's internals that you could not have got by prompting it. The authors import a philosophical term for exactly that surplus — *privileged information*, information reachable by inspecting internal states but not by black-box prompting — and make it the falsifiable criterion for the whole family. Their worry is not that verbalizations are wrong in the ordinary sense, but that they can be plausible and useful-looking while being generated entirely from the input text or from the verbalizer's own world knowledge. The larger goal is evaluative: if we are going to audit models by asking them, or by asking a second model to describe the first, we need benchmarks that can fail.

## What they studied

Two 8B instruction-tuned models — Llama-3.1-8B-Instruct, and Ministral-8B-Instruct-2410 as a second family — used as target and verbalizer, in three arrangements: same model (the default and the one prior work used), target Llama3 with verbalizer Ministral (cross-family), and target and verbalizer both fine-tuned on a synthetic persona corpus so that the knowledge they hold is controlled. Unit of analysis is a per-sample judgement: one activation (or a layer's worth of activations) is decoded into text, and the text is scored for whether it yields a known answer. The datasets are the ones prior verbalization work used for feature extraction — six relation sets (country→currency, country→food, person→sport, person→position, product→company, star→constellation) with between 36 and 1,344 examples each — plus a new three-variant persona dataset and, in the appendix, non-QA tasks including entity resolution.

## How they did it

Four experiments, each a different way to ask whether the activation carried anything the input did not. **(1) Strip the activation.** Ask the same question of the verbalizer with only the input text plus the interpretation prompt — no patching, no fine-tuned decoding — and compare against full verbalization. If the zero-shot-text-only baseline matches, the task never required privileged information. **(2) Replace the activation with a reconstruction.** Train an inversion model (T5-Base, and separately a Llama3 decoder) to recover the input text from the activation — on MS MARCO passages, out of domain for the evaluation sets — then let the model answer the interpretation prompt from the reconstruction instead of the activation. This is a *sufficiency* test in the other direction: whatever the verbalizer extracts via the text route is explained by input-text content surviving in the activation. **(3) Make the target's knowledge unguessable.** Train the target on biographies of invented people (PersonaQA), in three variants: attributes correlated with the person's sociodemographic name, the same attributes shuffled to break the correlation, and fully invented attributes (Fantasy). Here a correct verbalization can only come from the target's activations, because the verbalizer has never seen these people — except that the correlated variant is answerable from name statistics, which is the point of having all three. **(4) Survey the knowledge gap in both directions.** Fine-tune the verbalizer on the same fantasy corpus so its knowledge match the target's (then it should work), and separately keep the verbalizer fantasy-trained while the target stays uninformed (then it must not work, and any nonzero score is the verbalizer talking). Controls throughout: McNemar's test with Bonferroni correction against the relevant baseline, a logistic probe on the same activations as a non-generative reference read-out, and a prompt-perturbation stress test in the appendix with four semantically equivalent rewordings and two adversarial ones.

## What counts as an explanation here

Not an explanation in the interpretability sense at all — the deliverable is a *validity test* for a class of explanations. A verbalization is treated as a claim with the structure "this text describes information stored in this activation", and the paper's contribution is a set of experimental designs under which that claim can be false while the method still looks impressive. The object being tested is a pipeline of two models, so "faithfulness" here is a property of the pair (target, verbalizer) plus the prompt, not of a single network's internals; the authors make that decomposition explicit and it is why their failure modes are all interactions.

## How they judged success

Accuracy on out-of-domain questions generated from held-out personas or relation sets, with the answer counted correct if it appears among the first 20 generated tokens — deliberately generous to the verbalizer, since verbose generations fail under this rule. Significance is McNemar's on paired samples with Bonferroni correction across the comparison family, asterisks marking only cells that beat their own baseline; unstarred cells may be significantly worse. Baselines are named rather than assumed: the zero-shot text-only baseline for every verbalization comparison, an inversion-then-interpret baseline for the activation-as-contains-input hypothesis, a logistic probe as the non-generative read-out, an untrained verbalizer for the Patchscopes arm, and a per-variant persona dataset that separates answerable-from-statistics from only-answerable-from-activations.

## What they found

- **The standard evaluation is not a test of privileged information.** On the six feature-extraction sets, a text-only zero-shot baseline averages 0.64 on Llama3 and 0.68 on Ministral, and LIT averages 0.64 and 0.61 respectively — no better than the baseline that never sees an activation, with several cells significantly worse. Patchscopes averages 0.38 and 0.27, substantially below the baseline, which the authors partly attribute to the method's patch-into-every-layer scoring being order-dependent rather than to a property of activations. Their summary is blunt: these datasets can only show *whether input information survives into the activation*, not whether the model added anything.
- **Reconstructing the input reproduces most of the "verbalization" signal.** With layer-level activations inverted to text and the interpretation prompt answered from the reconstruction alone, scores come close to LIT on most tasks (e.g. 0.79 vs 0.79, 0.52 vs 0.45, 0.46 vs 0.41; the athlete tasks fall) and match or beat Patchscopes' whole-layer numbers. In the fair single-token comparison, inversion beats Patchscopes on every one of the six tasks. So a large part of what these methods were credited with describing is the input prompt, recovered well enough from the residual stream.
- **When knowledge is misaligned, the verbalizer answers from its own head.** With the target trained on shuffled persona attributes, verbalization does *worse* on the target's actual (shuffled) labels than on the original ones the verbalizer has priors about — the decoded text tracks the verbalizer's world model, not the target's. And on the fully invented personas, where no prior can help, neither LIT nor Patchscopes scores above zero across the six attributes. Both models are capable of the task when the knowledge is shared: after training the verbalizer on the same fantasy corpus, accuracy becomes comparable to a logistic probe trained on the same activations (e.g. 0.35 vs 0.38 on favourite food, 0.43 vs 0.20 on favourite board game).
- **Extra knowledge in the verbalizer is not an advantage either.** Keeping the verbalizer fantasy-trained and the target uninformed — a target that knows nothing about these people — still yields nonzero accuracy for both methods (up to 0.50 for Patchscopes on the board-game attribute), where a faithful translation would have to score zero. Expressivity in the verbalizer is thus a failure mode in both mismatch directions, not a resource.
- **The description is fragile to the question, which no interpretability method should tolerate.** Semantically equivalent rewordings of the interpretation prompt move accuracy by up to 60% on one relation set, with a net average change of −0.044 for LIT and −0.014 for Patchscopes; an adversarial phrasing that plants a wrong candidate answer flips the judgement easily, which is the signature of prompt-following rather than reading.
- **Two incidental methodological results worth carrying.** The same Patchscopes experiment run with jobs dispatched in parallel versus serially gives averages of 0.38 versus 0.49 — the invocation order changes the measured capability, which the authors flag as a reproducibility problem for analysis tools that are not trained. And in the cross-family setting (Llama3 activations into a Ministral verbalizer) both methods collapse (Patchscopes 0.00–0.22, LIT 0.00–0.20), so their claim that cross-model verbalization is promising is not supported by these numbers.

## Limits and open problems they name

QA-shaped tasks dominate, and the models are 8B-class because training an inversion model per layer is expensive; only layer 15 (following prior work) is inverted for the main experiments, with one extra layer in an appendix. Effect sizes on the non-QA tasks in the appendices are similar but not exhaustively reported. The paper does not show that verbalization cannot work — it shows that the current evaluation cannot tell working from not working, and it names the fix it did not run: construct examples where the target and the verbalizer would give *different* answers to the same prompt, and see whether patching the target's activation changes the verbalizer's answer. It also notes that its own inversion route is disadvantaged by the 20-token cutoff. There is no intervention arm in the paper at all.

## What we take from it

- **A required control for every read-out we publish: the input-only baseline.** Whatever our probe, lens or verbalizer reports about a component, the same question must be answered by a model that sees only the input, and our number must beat it — on Llama3 here, zero-shot *matched* LIT exactly (0.64 average). This is the same lesson the folder keeps meeting at other scales (a statistic without a known-negative input is a description), applied to the read-out itself rather than to the model. It costs one prompting run.
- **A decisive experimental design for "is this privileged": two models that disagree.** The paper's unfired final experiment is the one we can run cheaply — find inputs where a reference model's answer differs from the target's, patch the target's state, and check which answer the decoder produces. Any claim of ours that a decoded direction carries *the model's* knowledge rather than shared world knowledge should be stated over disagreement cases, because on agreement cases the claim is untestable.
- **A warning about verbalizer-as-surrogate.** If our white-box model is a trained decoder that eats activations and emits descriptions, then training it on data from the same distribution as the target guarantees it cannot be distinguished from a model describing its own knowledge — the fantasy arm is the clean demonstration that accuracy on a shared corpus is not evidence of reading. The corresponding validation set has to contain knowledge only one of the two models has.
- **A data-design constraint for our probing datasets.** Feature-extraction trivia (country→currency) is answerable from the prompt and from world knowledge, so it cannot discriminate a good read-out from a lucky one. Datasets for probing should be built the way PersonaQA-Fantasy is: information that exists only in the target's weights, verified by an untrained model failing it.
- **A reproducibility rule for interactive analyses.** A method whose measured score moves 11 points between parallel and serial dispatch is measuring something about the harness; report dispatch order and rerun any number that is close to a decision boundary.
- **A framing we should adopt verbatim in spirit.** "Privileged information" is a better-posed success criterion than "interpretable", because it can be operationalised as a difference from a black-box baseline rather than as a human judgement — the same move we already make by demanding that a predictor beat a prompted model.

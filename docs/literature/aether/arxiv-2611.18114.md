## What they wanted, and why

Interpretability in this paper is not forensic: it is generative. The authors argue that in scientific uses of neural networks — predicting brain responses to images, stories or audio — a model is only as useful as the computations a human can state about it, and the best predictors (trained deep networks) are the least statable. Rather than train a network and explain it afterwards, they ask whether a frontier coding agent can write the network itself, weight by weight, in readable code, with no gradient-based training at all, and iterate until it predicts as well as it can. The bet is that a search that can only move in human-scriptable steps leaves a human-scriptable artefact behind, so accuracy and legibility rise together instead of trading off. The paper is aimed at the long-standing gap in encoding modelling where hand-built feature pipelines (Gabor banks, texture statistics, gist) are readable but weak and pretrained networks are strong but opaque.

## What they studied

Two families of target. First, seventeen synthetic tasks — thirteen algorithmic (five-digit addition and multiplication, sorting, digit counting, parity, a five-bit boolean circuit, linear interpolation, word reversal, three-digit GCD, decimal-to-binary, Levenshtein distance, smallest prime factor, date normalisation) and four NLP (six-way TREC question type, SST-2 sentiment, MRPC paraphrase, SNLI entailment) — solved by a three-layer, width-64 GPT-style transformer whose weights the agent writes. Second, three brain-encoding datasets: 7 T visual-cortex fMRI from five subjects viewing natural images (with the Natural Scenes Dataset held out entirely for cross-dataset testing), language fMRI from three subjects listening to podcast narratives, and intracranial ECoG from one patient (plus five more for transfer) over seven days of natural audio. The unit of analysis is the whole program: its code, its numeric constants, and the individual feature maps or weight blocks it defines.

## How they did it

A frontier agent (Claude Code running Opus 5.5, Sonnet 5.5 or Haiku 5.5, with a restricted session of six file and shell tools and no web access) is given a task prompt and a fixed, non-editable evaluation script. The prompt and harness forbid optimisers, fitting loops, backpropagation and downloading pretrained weights; the agent must set parameters in closed form and may only use ordinary libraries such as PyTorch. It writes a model, sees a scalar score on a visible set, and revises, for roughly 30–50 iterations per run. On the algorithmic/NLP tasks the model must generate exact answers token by token; on the brain data the written program maps a stimulus to features and a fixed evaluator fits a ridge regression to the recorded responses and returns a Pearson correlation, with a cap of fewer than 10,000 features and fewer than 100,000 explicit parameters so that an overcomplete random basis cannot win. After the search the best models are re-scored on a hidden set the loop never saw. Three audits follow: a separate agent judges each saved model and its logs for rule violations and unreadable edits; the weight-writing code is re-run on altered task data to confirm the weights do not depend on it; and — the paper's central instrument — an agent describes the best model in at most 200 words, and a fresh session given only that description and the task rebuilds the model, after which the rebuild's accuracy, parameter count and per-example behaviour are compared with the original's and with a no-description control. Visual-cortex searches run in a sandbox with no network and no dataset access; the language and ECoG searches rely on the prompt plus post-hoc audit.

## What counts as an explanation here

A program, and specifically one whose numeric constants are human-chosen. The explanation is not a post-hoc description of learned weights but the weight-writing code itself: a shift-register of attention heads, a lookup table of hand-written word patterns, a block of three ReLU units, a Gabor bank cascaded into five named mid-level modules. It is explicitly partial — the paper accepts that the models capture known motifs rather than new computational principles, and that a 200-word summary carries most but not all of a model. It is predictive by construction (the artefact *is* the predictor), and the text-bottleneck test makes "is it explainable" an operational question: an explanation is sufficient if a fresh agent can rebuild something from it that behaves like the original, at modest size.

## How they judged success

Hidden-set exact accuracy on algorithmic tasks and hidden-set accuracy on NLP splits; parameter count of the smallest model reaching full visible accuracy (compression); Pearson correlation pooled over voxels and subjects for the encoding models, on held-out images, held-out datasets (NSD, 998 shared images after excluding LAION-fMRI overlaps) and held-out subjects; seven classical interpretable baselines (Gabor, Gabor with divisive normalisation, GIST, HMAX, wavelet scattering, Portilla–Simoncelli texture statistics, a contour-curvature model), a single ridge fit to all seven concatenated after per-baseline rescaling, and pretrained AlexNet at pre-fixed layers (conv3 early, fc6 ventral). Explanation quality is scored by the text bottleneck against a no-description control (parameter ratio on a geometric mean, per-example error correlation, share of identical outputs), and by control checks that rebuilt weights are invariant to altered task data and that no session read outside its sandbox. Area attributions use an exact per-computation split of a voxel's test correlation, plus a unique-variance refit arm.

## What they found

On the algorithmic tasks the Opus runs reached 100% visible *and* hidden accuracy in all 26 runs (Sonnet 25 of 26, Haiku 25 of 26), usually by translating a textbook algorithm into weights: edit distance as one block per dynamic-programming row, multiplication as shifted partial products, GCD as a single three-ReLU block repeated a thousand times. NLP was harder — three of four tasks landed well above a majority baseline and paraphrase failed outright; TREC hidden accuracy was 87.3% for Opus, 86.6% for Sonnet, 71.1% for Haiku. Algorithmic runs hit 99% visible accuracy inside the first tenth of their iterations and spent the rest compressing, from roughly 3,400 parameters to about 200; the smallest full-accuracy model had a median of 166 parameters for Opus against 41,600 for Sonnet and 100,000 for Haiku, a 29× median reduction from the first model that reached 100%. Rebuilding from a 200-word description reproduced all thirteen algorithmic models at 100% hidden accuracy, and NLP rebuilds lost about 1.4 points; rebuilt algorithmic models were 1.74× the original's parameters against 2,043× for the no-description control, and NLP rebuilds correlated 0.74 with the original's hidden predictions against 0.51 for controls. In visual cortex the final program (865 lines, 9,996 features from 14 explicit computations) beat all seven interpretable baselines on every one of the four NSD subjects, by 0.443 to 0.400 in early areas and 0.317 to 0.256 in ventral, and beat the joint ridge over all seven (0.283 ventral) while trailing AlexNet in ventral (0.391) and matching it in early. Held-out subjects replicated the ordering (0.518 versus 0.472 early; 0.409 versus 0.309 ventral). Per-computation shares shifted systematically with the hierarchy — surface geometry from 38% in V1 to 15% in PPA, Gabor energy from about 10% in V1–V3 to under 3% in FFA and PPA, contour curvature under 5% in V1–hV4 to 15% in FFA — though the correlations are heavily shared (88–96% of squared correlation), so the unique-variance refits are far smaller and sometimes negative. The language-fMRI run produced the paper's most interesting failure: after a long slow climb the score jumped from 0.067 to 0.104 in one step, and the features responsible encoded word position in the story rather than its content — they alone reached about 0.090, above the 0.079 GPT-2 XL baseline, and tracked a scan-edge artefact (response abnormally high at scan start, low at scan end, present in all three subjects) at a correlation of 0.97. The authors recommend trimming roughly 40 TRs at each end of each scan, in training as well as testing, going beyond the release's removed 20. On ECoG the written features started at 0.039 and ended at 0.074 on the surface grid against Whisper's 0.082, led Whisper on 77 of 166 electrodes, and — the claim that matters — explained 6% of the combined model's variance that Whisper alone did not, lifting a joint ridge from 0.070 to 0.075 (95% bootstrap interval 0.0039 to 0.0064), improving on 126 of 166 electrodes. Across five further patients the learned early motifs transferred (model-to-model performance correlated 0.80 to 0.94) but the late refinements did not, adding 0.004 on the design patient and at most a thousandth elsewhere. Total API cost of all experiments: about $17,500 at list prices.

## Limits and open problems they name

Agents combine known motifs rather than inventing new computational principles; the discovered models are shallow parallel banks of one- or two-stage computations feeding a linear readout, and the authors attribute the residual gap to deep networks exactly there — matching AlexNet in early visual cortex, trailing in ventral, harder language and speech. Programming deep hierarchies without backpropagation is stated as open. The method leans on the agent's written explanations staying faithful to its weight edits, which the audits support for current frontier models but may not for stronger ones. Search is slow and token-expensive. The neuroscience results are observational, with few subjects and no causal interventions: area attributions describe which explicit computations predict responses under one hypothesis set, not unique mechanisms. The `write_weights` harness cannot actually prevent the agent's own Python from computing an answer outside the network, so the no-training rule is enforced by audit rather than by construction.

## What we take from it

A framing and a test: **an explanation is sufficient when a fresh reader can rebuild something from it that behaves the same.** The 200-word text bottleneck is the cheapest proxy we have for that and it comes with a proper null (the no-description control, whose models are enormous and worse-correlated), a proper size axis (parameter ratio against the original), and a behavioural axis (per-example error correlation, not just accuracy). For our own white-box model this inverts the usual direction of work: instead of probing a trained network and hoping the probe description means something, we can ask an agent to *write* the predictor in readable form under a no-training constraint, and then check that the resulting code is what a reader could have written from a summary. The paper also supplies the sharpest confound-detection story in this folder — an interpretable model that is rewarded purely on prediction finds a scan-edge artefact, sails past a strong black-box baseline on it, and is caught only because the winning feature can be read — which is the practical use of legibility and a warning about any metric-dominated search. And it prices the ceiling honestly: agents find known algorithms, not new ones, so what we would get from this route is a transparent recombination of our prior knowledge, not discovery.

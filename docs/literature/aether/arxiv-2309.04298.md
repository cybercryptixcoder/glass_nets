## What they wanted, and why

The applied situation they start from is the one everybody actually faces: someone wants the strength of a causal effect, has no expert-supplied graph, and so runs the standard two-step recipe — learn a graph, then compute an interval as if that graph were given. They argue that this recipe is wrong twice over. First, the interval ignores that the graph was chosen from the same data that produced the interval (the familiar double-use-of-data problem), so it is optimistic about the size and even the existence of the effect. Second, and the point they press harder, resampling does not rescue it, because the estimator one would resample is a composition of a discrete choice and a smooth estimate, and that composite is not smooth — the set of covariance matrices admitted by at least one admissible graph is a union of smooth pieces glued at singularities, so the bootstrap's asymptotics are not something you can predict. Their goal is therefore a confidence set for the total causal effect that carries *both* kinds of uncertainty — which structure, and how big the effect — with a coverage statement that does not depend on a graph having been guessed right. They frame this as the opening of a line rather than a finished solution, and they are explicit that it is tractable only at small to moderate dimension.

## What they studied

Linear structural equation models with jointly Gaussian, homoscedastic errors — one common unknown error variance across all variables. This is the setting in which the graph is identifiable from observational data alone (the Peters–Bühlmann equal-variance result they build on), so a total causal effect is a well-defined functional of the covariance matrix. The unit of analysis is the whole admissible graph *class*: their model is literally the union, over all directed acyclic graphs on d nodes (equivalently, by an inclusion argument, over all complete graphs, i.e. all causal orderings), of the covariance matrices each graph admits under equal variances. The estimand is the total effect from one variable to another — the summed products of edge weights along all directed paths — treated as a scalar to be covered by a set. Simulations run to six and twelve variables; the real-data illustration is the Sachs protein-signalling data with ten proteins.

## How they did it

The construction is test inversion, and every step is forced by what they cannot do. Rather than estimate the effect and attach an interval, they fix a candidate value and *test* whether the data are compatible with the effect being that value under *some* admissible structure, then collect all values that are not rejected. Two things make that test hard: the null is a union of one null per graph, and the union of smooth pieces is not smooth, so no standard likelihood-ratio asymptotics apply. Their answer to the union is the intersection-union principle — reject the union only if every single-graph null is rejected, which keeps the level valid without any correction over graphs. Their answer to the non-smoothness is to widen the alternative: keep the null restricted to equal-variance models of a fixed ordering, but relax the alternative to *all* positive definite covariance matrices. That makes the statistic a relaxation and the test conservative, but it also makes each cell a clean likelihood-ratio problem on a smooth manifold, so its limit law is a chi-square whose degrees of freedom are the number of constraints imposed — one more constraint, and so one more degree of freedom, when the effect is non-zero and the source precedes the target, one fewer when the target precedes the source (that branch can only mean a zero effect). A second route replaces the asymptotic bound with a split-likelihood-ratio / universal-inference test: split the sample, fit the alternative on one half, evaluate both hypotheses on the other, and use a fixed threshold derived from Markov's inequality — no regularity conditions, finite-sample validity, and visibly wider sets. Computationally they never enumerate the d! orderings: a pruning routine walks the ordering tree from the source node and deletes any partial ordering whose partial maximum likelihood already exceeds the critical value, and because the maximum likelihood under a fixed ordering collapses into d separate least-squares problems, partial likelihoods are cheap to compute; only the constraint that links the effect to the coefficients of variables on paths from source to target keeps a small joint subproblem, solved numerically. Testing proceeds outward from the maximum-likelihood effect estimate in fixed steps, and the resulting set can be several intervals plus an isolated zero.

## What counts as an explanation here

A confidence region: a subset of the real line for the total effect, reported as a set of values that survived testing, explicitly allowed to be non-convex — a non-zero interval together with a point mass at zero standing for the possibility that no directed path carries effect. It is a partial and deliberately hedged object: it says nothing about which graph is true, and it never claims to answer the question when the answer is not point-identifiable. The distinction they insist on is between a set that covers and a set that is informative, and the paper's own framing is that the covered set is the honest unit, with informativeness as a separate, empirically measured property.

## How they judged success

Empirical coverage of nominal 95% sets over 1000 replications per cell, on randomly generated 6-dimensional and (for one panel) 12-dimensional graphs, varying sample size, mean edge weight (which they use as a proxy for how much structure uncertainty there is), and graph density. Baselines: the two-step bootstrap with the equal-variance greedy discovery algorithm (GDS) and, in the real-data section, bootstrap plus the non-Gaussian LiNGAM method. Secondary measures: mean width of the non-zero part of the set (informativeness), the fraction of times zero is included when a non-zero effect is true (direction uncertainty), and computation time against dimension and sample size. They also run a robustness arm where the data are generated with *unequal* error variances spanning a range of deviation strengths, on the argument that the equal-variance target is then a misspecified-but-useful approximation, and measure what the coverage does. The real-data arm counts, for 90 pairwise effects among ten proteins, how many intervals cover the effect computed from the conventionally accepted reference structure — an external yardstick, not ground truth.

## What they found

- Coverage: both of their methods sit at or above nominal across every cell of the 6-dimensional table — in the table's 36 numbered cells every value is 0.98 or higher — while the two-step bootstrap falls to 0.70 at edge weight 0.05 with 100 samples in the sparse setting, and reaches 0.98 only at large edge weights where structure uncertainty is small by construction.
- Their own conservatism is diagnosed, not hidden: they attribute it to the two relaxations (intersection-union over graphs, unrestricted alternative), which is the price of validity without smoothness.
- Informativeness splits by density in opposite directions, and they say so plainly: dense graphs give *wider* intervals for effect size (more paths, more weights contributing) but *less* direction uncertainty (the ordering is easier to pin down), and sparse graphs are the mirror image — narrower size intervals, more structure uncertainty. Any summary that reports only width would therefore be reporting the wrong difficulty.
- The likelihood-ratio version is the informativeness winner and the split version the validity winner; they state that the split version is the only one with a finite-sample guarantee, and do not claim the winner on width also wins on rigour.
- Real data: 84 of 90 pairwise effects covered by their intervals, against 66 for the GDS bootstrap and 72 for the LiNGAM bootstrap; and 67 of 90 intervals straddle zero, against 35 and 55 — i.e. the narrower baselines are narrower largely because they are more confident than the data support.
- Computation: feasible "over all causal structures" at d=12, and cheaper than the bootstrap baseline in the dense setting because fewer orderings survive pruning; more data makes it *faster*, since less structure uncertainty means a smaller surviving ordering set. At d=2 there are already more than 10^87 graphs, which they use to bound the method's reach.

## Limits and open problems they name

Identifiability is assumed, not manufactured: without equal variances (or another identifiability condition) every covariance matrix entails a set of effects that always contains zero, so within their framework the honest answer collapses to something inconclusive — they say this directly rather than proposing a patch. The relaxation of the alternative means the guarantee is conservative by construction, with no claim of tightness. The search over structures is all-or-nothing and exponential; beyond moderate dimension they offer only a compromise, in which the practitioner fixes the parts of the structure they trust and quantifies uncertainty over the rest — a partially quantified region, with no coverage claim attached to the fixing. The real-data check uses a reference graph as if it were truth. Generalisation to non-Gaussian noise, additive-noise models and other causal functionals is named as future work, along with the bivariate case of their earlier paper which handles non-Gaussian errors heuristically.

## What we take from it

- **A measure, and the sharpest form of the half-reporting warning the folder already carries.** Run 541's paper reported coverage and width together; this one adds the third number that the pair still misses: *the fraction of sets that contain the null*. Their own table shows the three quantities do not move together — dense graphs buy direction certainty at the cost of width, and sparse graphs do the reverse — so the triple, not the pair, is what distinguishes "informative" from "merely covering".
- **A warning with a mechanism, not just an observation.** The reason the two-step bootstrap fails is not small samples; it is that the estimator being resampled is non-smooth because the model is a union of manifolds meeting at singularities. Run 540 concluded from a similar comparison that resampling a threshold-crossing pipeline is the wrong default; this paper supplies the explanation, which makes it a rule we can apply in advance rather than a result we discover in a table.
- **A shortcut worth stealing outright.** Because the union null is rejected only when every member is rejected, a battery of per-account tests composes into a valid test over all accounts with *no* multiple-comparison penalty — the conservative direction is the correct direction when the claim is "no account explains this". This is the cheapest known way for us to turn a collection of per-site or per-account verdicts into one set-valued statement, and it needs no assumption that the collection was enumerated correctly.
- **A framing for the pruning.** Their search deletes an ordering as soon as its partial likelihood exceeds the threshold, and the deletion is *sound* because the maximum likelihood decomposes across nodes once the ordering is fixed. Any of our account searches that prunes on partial evidence needs the same argument printed next to it: pruning is only sound if the partial objective is a monotone lower bound on the full one.
- **A caveat for the relaxation route.** Widening the alternative to make the null smooth is what buys the chi-square law, and it is exactly why the sets are conservative; a battery that widens its alternative to get a tractable null should state that it has traded tightness for validity, and should not then report its own width as if the trade had not happened.

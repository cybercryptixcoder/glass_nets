## What they wanted, and why

Two established ways of explaining a model behaviour were unsatisfying to these authors for opposite reasons. Circuits drawn over attention heads, MLP modules or neurons are causally legible but the units are polysemantic, so the resulting graph is hard to act on. Methods built on fine-grained, named units — probing, concept vectors, causal abstraction from a hypothesis — are legible but presuppose that the researcher already knows the behaviour and has data that isolates it, which rules out *discovering* mechanisms nobody anticipated. Their proposal is to keep the fine-grained unit and change where it comes from: use sparse autoencoder features as the nodes of the circuit, so the graph is both nameable and causal. The larger goal is a pipeline that goes from raw text to thousands of circuits without a human deciding what to look for, and a demonstration that such graphs are not merely descriptive — that editing a named feature changes how the model generalises. Code, data and autoencoders are released.

## What they studied

Pythia-70M throughout, at SAEs trained on attention outputs, MLP outputs and residual-stream vectors for every layer (expansion factor 64× the model width), including an SAE on the embedding layer. The unit of analysis is a *node in a computation graph*: an SAE feature activation or an SAE reconstruction error at a given token position, and edges between such nodes. Three settings carry the evaluation: four subject–verb agreement tasks adapted from Finlayson et al. (simple, within a relative clause, across a relative clause, across a prepositional phrase); a linear profession classifier on Bias in Bios read out from penultimate-layer activations; and a fully unsupervised pass over clusters of Pile contexts.

## How they did it

They treat the SAE decomposition as part of the model rather than as a lens on it: the forward pass is rewritten so that each activation is replaced in-graph by its sparse reconstruction plus an explicit error term, both of which then become differentiable nodes. Indirect effects (Pearl-style: the change in a metric when a node is set to its counterpart's value, or to zero when there is no contrastive pair) are then estimated for every node and every edge with a linear approximation rather than measured one node at a time — a first-order attribution-patching estimate for the cheap version, and an integrated-gradients estimate over ten interpolation points where the cheap one is known to underestimate (early residual stream and the layer-0 MLP). Edge estimates correct for non-transitive paths by subtracting products of Jacobians through intermediate nodes. Nodes and edges are kept above a threshold to form the circuit. On the contrastive tasks the metric is a verb-form logit difference across clean/patch pairs; on the classifier and the unsupervised pass the metric is the negative log-probability of the correct label with zero ablation. Once a circuit exists they hand-label each feature by inspecting top-activating Pile contexts and the tokens whose probabilities it most affects when ablated, and for the classifier they ablate features judged irrelevant to the intended label. For the unsupervised arm they cluster Pile contexts by model activations, sparse feature activations, estimated indirect effects, or sparse random projections of parameter gradients, then run the same circuit discovery inside each cluster.

## What counts as an explanation here

A sparse feature circuit: a directed sub-graph over named SAE features (plus explicitly marked error nodes) with signed edge weights, hypotheses about roles at each node, and a graph summary that groups features into role-clusters (number detectors, boundary detectors, verb-form promoters) across token positions. It is a causal account of *one behaviour on one dataset*, partial by construction — the error nodes are inside the graph precisely because the dictionary does not cover the activation. Prediction is stated in the mechanism but never scored against a held-out intervention: beyond § 3's ablations, the paper's predictive objects are the attention-decomposition reported by the later work that cites it, not a prediction this paper tests. Description and causal check are welded together — a feature's name is only used after a human reads it, and its role in the graph is fixed by estimated effect size — which is the right order but also means a mis-named feature would still carry a correctly-placed edge.

## How they judged success

Three named criteria — **interpretability**, **faithfulness** and **completeness** — and a strong preference for reporting them against the same pipeline run with neurons in place of features. Faithfulness is the metric value with everything outside the circuit mean-ablated, rescaled between the empty circuit and the full model; completeness is the faithfulness of the circuit's *complement*. Thresholds are swept rather than picked (node threshold T_N, edge threshold T_E) and curves are plotted, which is what lets the paper state "N nodes to explain this fraction". Interpretability is measured by crowdworkers on a 0–100 scale, on four arms (random features, circuit features, random neurons, circuit neurons), blind to condition — with the acknowledged limitation that the raters were recruited from an alignment-research Slack channel rather than sampled randomly. The classifier arm adds the controls the causal claim needs: a neuron version of the same edit procedure, a *feature skyline* that picks the same number of features by measured effect on the unintended label instead of by human judgement, a *neuron skyline* given that same unfair advantage, a concept-bottleneck probe baseline, and an oracle trained on ground-truth balanced labels. The unsupervised arm has no evaluation at all and the authors say so.

## What they found

On agreement, feature circuits reach the same faithfulness with far fewer nodes than neuron circuits — under a hundred nodes carry most of the task performance where neuron circuits need roughly fifteen hundred to reach half — and the complements mirror this: ablating a few feature nodes destroys task performance, where hundreds of neurons are required. Their interpretability ratings separate cleanly (circuit features about 62 on the 0–100 scale against about 30 for circuits' neurons, and about 82 against judging-workflow neurons on the classifier arm). The case study yields a two-pathway algorithm for agreement across a relative clause: subject number is detected at the subject, boundary detectors mark the start of the modifying clause, and the number is carried to the final position, where verb-form promoters act; the across-prepositional-phrase circuit shares most of its features with it, while simple and within-clause agreement are structurally simpler. In the classifier arm the biases are removed almost completely: profession accuracy on balanced data goes from about 62 to about 89, gender-predictability from about 87 to about 54 and worst-group accuracy from about 24 to about 76, matching the feature skyline and approaching the oracle at about 93; the neuron version was abandoned because almost none of the implicated neurons could be interpreted, and even the neuron skyline lagged badly. In the unsupervised arm the discovered circuits for succession and induction reproduce mechanisms known from head-level work, and circuit-level inspection shows at least two clusters that looked like single mechanisms are unions of two distinct ones.

## Limits and open problems they name

Everything depends on a good dictionary existing for the model, and training one is a large up-front cost they deliberately treat as out of scope; whatever the SAE misses stays opaque and reappears as an error node (SAE error accounts for roughly 1–15% of activation variance here). Removing residual-stream error nodes badly damages the model, so the graph's error discipline is not uniform across component types. Much of the evaluation is qualitative, and they name the central gap plainly: evaluating dictionaries and circuits without a downstream task is hard, and "while evaluating these clusters and circuits is an important open problem" is their own phrasing for the unsupervised half. The classifier arm leans on one dataset, one model and one linear probe, and the linear-probe choice was itself forced — logistic regression on final-layer representations did not get above chance, for reasons they do not explain. Human labels are crowd ratings from a self-selected expert pool, and the authors note it biases toward semantic groupings over syntactic roles.

## What we take from it

A **method** and a **measure**. The method: rewrite the model's forward pass so the dictionary's features and its residual are in-graph, then estimate indirect effects for every node *and every edge* with one backward pass (integrated-gradients variant where the cheap one under-reports), so the cost of a component-level account is linear in the number of passes rather than the number of components — and the account includes the parts the dictionary misses as first-class nodes instead of silently dropping them. Two reporting habits to copy outright: **error nodes are drawn, not hidden** — the fraction of total effect attributed to dictionary error is printed next to every circuit, and the authors note it falls as the dictionary improves, making it usable as a dictionary-quality read-out; and **faithfulness is always paired with the complement**, so a circuit is priced twice, by what it explains and by what its removal destroys, which is the only way to distinguish a graph that carries the behaviour from one that merely overlaps it. The **warning** is the matched-neuron arm: the honest comparison runs the identical pipeline with neurons in place of features, and the paper notes the neuron skyline is *deliberately given an unfair advantage* — which is exactly the discipline our own read-outs need when we claim a finer unit is "more interpretable". The **shortcut** is the skyline-as-selection arm: the same 55 features, chosen by human judgement of task-relevance, against the same count chosen by measured effect on the spurious label, tie — so the value of the dictionary here is not that a human can name spurious features better than a metric can pick them, it is that a human can name them without the special-purpose labels a metric would need. Coreference `arxiv-2405.08366` (the skyline priced on IOI, and the entry that cites this paper's feature-level decomposition as the predictive object worth copying), `arxiv-2606.16939` (observational fit of a feature graph, no per-intervention cost), `arxiv-2505.23556`.

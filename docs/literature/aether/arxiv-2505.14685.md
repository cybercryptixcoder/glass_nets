## What they wanted, and why
Theory-of-mind benchmarks tell you whether a model answers a belief question correctly and nothing about how. The authors want the algorithm: when a story plants two facts that bear on one question and only one of them is the right referent, what does the model do internally that a lookup table would not explain? Their hypothesis, stated before the experiments, is a *lookback*: rather than trying to anticipate every later question and push each candidate fact forward as it is encountered, the model stamps a small reference into the token where the fact lives and a copy of that reference into a later token, so that when the question arrives an attention head can dereference the pointer and pull the payload forward only if it is needed. Belief tracking is the test bed because the correct fact is conditional on who is asked and on who could see what, which forces exactly this deferral. The larger goal is to reverse-engineer one complete multi-step algorithm inside a frontier LM — a proof of concept that a capability described only behaviourally can be given an end-to-end mechanistic account.

## What they studied
Three instruction-tuned models: Llama-3-70B-Instruct (FP16) as the primary, with Llama-3.1-405B-Instruct (INT8) and Qwen2.5-14B-Instruct (FP32) as replications. The unit of analysis is a *pair* of tokens — a source reference token (character, object, state, or the visibility sentence), a recalled token (the state token that holds the payload), a lookback token (the question and final answer colon) — and the objects localized are low-rank subspaces of their residual streams (and, in the ablations, query and value weight matrices). Data is CausalToM, built for this paper: four templates on one story shape (two characters, two opaque objects, two states), with and without explicit visibility sentences, drawn from 103 characters, 21 objects and 23 states. Analysis runs on the 80 original/counterfactual pairs that the model answers correctly.

## How they did it
Two stages, coarse then fine. The coarse stage is causal mediation analysis on the residual stream: build an original prompt whose question names a character absent from the story (so the model answers *unknown*) and a counterfactual whose story contains that character, patch the counterfactual's residual vector at one source token into the original run layer by layer, and read where the answer flips from *unknown* to a state token. That gives a flow map without saying what travelled. The fine stage is causal abstraction: write a high-level causal model as pseudocode — assign an *ordering ID* to each character, object and state (first or second of its type, independent of the token's identity), copy the character and object OIs as addresses onto the state token bound to the state OI, copy their pointers to the final token and dereference — then align that model's variables with LM activations by targeted interchange interventions and score agreement with interchange-intervention accuracy (IIA). The interventions are designed so that the causal model makes a *surprising* prediction, which is what makes them informative: patching only the pointer from a counterfactual whose state order differs should produce an answer that matches neither run (the other state from the *original* story), and it does. To localize a variable below the whole residual vector they use desiderata-based component masking — learn a sparse binary mask over singular vectors of the activation that maximizes the logit of the hypothesized causal-model output — and report every experiment on both the full vector and the identified subspace. Visibility is handled by a third lookback: a visibility ID generated at the sentence that states who can see whom, dereferenced to update the observing character's beliefs. Validation includes knockout experiments that restrict attention from the second visibility sentence to a chosen prior sentence one layer at a time, and a correlation analysis projecting per-head query and value weight blocks onto the causal subspace. Generalization is probed by replaying the pointer, payload and OI interventions on BigToM, and the two replication models rerun every main intervention.

## What counts as an explanation here
A program with explicit variables, plus a localization of each variable in the network — a causal abstraction in the technical sense, not a description and not an attribution graph. The form is deliberately intermediate: a handful of named objects (character OI, object OI, state OI, binding payload, binding pointer, answer address, answer payload, visibility ID) with a copy-and-dereference operation connecting them, each mapped onto a layer range at a named token. It is partial in the sense that it covers one task family on simple stories, and predictive in a narrow but real sense: because the model is stated as variables with structural roles, an intervention on a variable makes a specific behavioural prediction (including the neither-run prediction above), and that prediction is what is checked. The claim is explicitly about computation, not about belief, sentience or intent — the ethics statement separates the two.

## How they judged success
The single metric is interchange intervention accuracy: train nothing, intervene on both the causal model and the LM, and count the fraction of the n = 80 cases where the intervened model and the intervened network produce the same output. Each experiment is plotted as a layer-wise curve, so the *pattern* — where alignment rises, where it falls, and whether it falls in between — is the evidence rather than a scalar. Several controls carry weight: a source-reference intervention that should leave the output unchanged unless the address-bearing token is frozen (freezing the state token's residual stream is what makes the alternate state appear, per Appendix I), the both-address-and-pointer intervention that restores alignment across the gap where single-token interventions fail, and the knockout/attention-restriction experiments for the visibility payload. Model selection is gated by behaviour: Table 1 reports accuracy over ten runs of a hundred samples per model, and only models above 80% in both conditions are analysed. Subspaces are identified with a learned mask, so the alignment claim is made twice — once for the full residual stream and once for the low-rank subspace. A per-head weight-projection correlation to the causal subspace is offered as converging evidence, not as the test.

## What they found
Ordering IDs are the reusable primitive: the position of a character, object or state in the story is encoded in a low-rank subspace of its token's residual stream, and patching a token that has identical surface form but a different OI changes the computation in the way the causal model predicts — which rules out token identity as the carrier. The no-visibility algorithm runs in five stages, each localized: character and object OIs in their own tokens at layers 20–34; transfer of those OIs onto the state tokens at layers 33–38, where the address sits beside the state-OI payload; pointer copies moved to the final token by layer 34; the state OI represented at the final token across layers 34–52; and the dereference that fetches the state token's value at layers 52–56. Swapping the answer payload at the final token changes the output to the counterfactual's state in all 80 cases once layers past 56 are patched, and swapping only the answer pointer anywhere in 34–52 redirects the model to the other state of the original story in all 80 cases — the prediction that distinguishes a pointer from a copied value. The binding-lookback swap (addresses plus payload at the two state tokens, pointers untouched) peaks between layers 33 and 38, and the source-reference swap with the state token frozen aligns at layers 20–34. Under explicit visibility, the visibility ID is generated at the visibility sentence and remains dereferenceable there up to layer 23, after which it splits into an address and a pointer copy; intervening only on later tokens aligns after layer 31, intervening on both the visibility sentence and the question aligns from layer 10 onward, and the intermediate band 24–31 is where single-sided interventions fail because the address and the pointer disagree. Knockouts show the second visibility sentence pulls information from the prior sentences even after the character OIs are available, which is read as the payload carrying the observed character's OI. Behaviourally, visibility is where models break: Qwen2.5-14B-Instruct 0.962 no-visibility / 0.912 visibility, Llama-3-70B-Instruct 0.952 / 0.923, Llama-3.1-405B-Instruct 0.883 / 0.970, while Llama-3.1-8B-Instruct falls from 0.722 to 0.310 and Meta-Llama-3-8B-Instruct from 0.349 to 0.085. On BigToM the same interventions localize the queried-character OI at layers 9–28, the answer pointer at 33–51 and the answer payload after layer 59, close to the CausalToM bands but not identical — and the paper reports that the subspaces carrying these variables do *not* coincide across the two datasets even where the variable semantics do.

## Limits and open problems they name
The stories are simple and the templates few, so the mechanism is demonstrated on a task the models already solve near-perfectly and on 80 correct cases; the authors note that most other ToM benchmarks remain hard enough that the analysis cannot be run on them. BigToM supports only the pointer, payload and OI interventions — the full set does not replicate because the benchmark's stories lack coherent counterfactual structure — so cross-benchmark evidence is called preliminary. Subspace intervention is not run on the two replication models at all, and only the Llama-3-70B results are shown in the main text, with Qwen2.5-14B and Llama-3.1-405B in an appendix. The visibility payload's exact semantics are undetermined: the two-character setting cannot say whether it carries the observed character's OI, only that observations are consistent with it. The finding that the *same variable* occupies *different subspaces* in CausalToM and BigToM is flagged as unexplained and left for future work. There is no ablations section isolating a head or a circuit, and no measurement of what happens when the lookback is interrupted without a counterfactual substitute.

## What we take from it
Three things, and the first is the strongest form of an explanation the folder has yet recorded. (1) **The causal abstraction is the shape our white-box model should take, and the load-bearing detail is that the abstract model must predict something counterintuitive.** Patching only the pointer produces an answer belonging to neither run; patching the payload produces the counterfactual's; the two are different curves at different layer bands. A read-out that only reproduces the original output under an identity intervention is a restatement, and the test that separates a real abstraction from a fit is whether an intervention on a *variable* makes a prediction no simpler account makes. Our own accounts should be written as named variables with copy/dereference/arithmetic operations over them, and each variable should carry at least one intervention whose predicted outcome is surprising. (2) **Copying a reference to two places is what buys conditional reasoning, and it is directly checkable at the weight level.** The pointer/address/payload triple is a QK/OV statement — the pointer's query direction lines up with the address's key at the recalled token, and the OV writes the payload — so a claim of this form can be audited without behaviour by projecting each head's query and value weight blocks onto the identified subspace, which is exactly the sort of weight-side check our project wants: the interpretation is a statement about matrices, and the matrices are inspectable. (3) **A null in the middle of a layer sweep is evidence of a two-sided mechanism, not of absence.** For the visibility lookback, intervening on only the recalled side or only the lookback side leaves IIA at chance between layers 24 and 31, and intervening on *both* restores alignment from layer 10 onward: when a mechanism is a matched pair, any single-sided probe must null out precisely where the pair is split. This is a general warning for our patching batteries, where a null band inside an otherwise-aligned sweep has repeatedly been read as "no effect"; the correct inference is that the intervention was on one half of a conjunction. Two smaller items. The *ordering ID* is a representation whose content is positional rank abstracted away from token identity, encoded in a low-rank subspace, and validated by intervening on tokens with identical surface form but different OIs — a clean template for testing any variable we claim to have found, since it asks the network to distinguish two inputs that differ only in the hypothesized variable. And the failure pattern at small scale is worth carrying as a difficulty metric: adding explicit visibility costs Llama-3.1-8B-Instruct 41 points while the 14B and 70B models barely move, so a two-hop relational condition is a cheap discriminator of whether a model is doing the computation or a shortcut, which is a useful way to choose which models our read-outs are worth fitting.

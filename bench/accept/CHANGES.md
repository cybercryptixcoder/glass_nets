# Change ledger: the acceptance suite's interface and scorer code

*Public ledger (`docs/spec/BENCH_BRIEF.md` §2). Only changes to the interface and to the scorer's code are logged here;
everything sealed is logged privately. A scorer bug is fixed in both copies as a new, named version.*

| version | date | change |
|---|---|---|
| interface bench-accept/v1 (draft) | Nov 27, 2026 | First version: task folder, blueprint, allowed map classes, invented primitives (200 AST nodes), the network's own choice, run alone, the `Box` protocol, the verifier hook. Adopts vocabulary v2 (f0b3b680) unchanged |
| scorer-v1 | Nov 27, 2026 | Development copy of the scorer: format check, run alone in a separate process, interchange on decisive pairs (at least 20 per tested part) with family-wise random-subspace controls (99th percentile of the best of K, K = parts tested), substitution, kept parts suffice (5th percentile), overview, recovery of sealed variables (agreement or correlation, and substitution at the sealed location), S5a checks (run alone against the task-rule baseline; a lookup at the decision must be at chance on fresh inputs). "No value" (an all-zero categorical reading, declared by `null_below`) agrees only with "no value" |
| interface bench-accept/v1 | Nov 27, 2026 | Completed: the reference true blueprint (`reference/frac_prevs/`, INTERFACE.md §8); the categorical encoding's optional `null_below` |
| scorer-v1.1 | Nov 27, 2026 | Speed only: interchange predictions evaluate the blueprint once per pair set and recompute only the overridden part's descendants (large blueprints were too slow). Regression: identical statistics on the reference and on two dev-001 S0 true blueprints (every statistic equal to its stored value). New network format `mlp_relu`; the S5b check; `example_box.py` (a Box for testing the hook's plumbing, reads nothing sealed) |
| scorer-v1.2 | Nov 27, 2026 | **Observed failure:** the S1 self-check on dev-002 (06:38) passed 1 of 10 true blueprints at their own lines, with every statistic reproduced exactly. **Cause, by minimal reproduction** (dev-002 S1-seq-00 and -01): (1) a sealed variable's own substitution score and the box's were computed on different random pairs (one generator used in sequence), so a box equal to the true blueprint could lose by noise; (2) "every level" compared numerical values by exact agreement, which is near 0 for any trained network; (3) a part located on its whole site (here the 2-dimensional output) has random-subspace controls identical to itself, which made the family-wise line near 1 for every part. **Change:** (1) own and box substitution on the same pairs (a fixed seed per sealed variable); (2) numerical levels scored by R2; (3) parts whose location spans their whole site are left out of the control family (their interchange is still scored and reported). **Test:** the dev-002 S1 self-check must pass 10 of 10 true blueprints after (1 of 10 before). **Cases not used to design it:** the dev-001 and dev-003 S1 networks. **Verdicts that must not change:** dev-001 S0 (10 of 10 true, 30 of 30 known-wrong) and S5a (31 of 31 rejected). Own scores of every calibrated draw recomputed |
